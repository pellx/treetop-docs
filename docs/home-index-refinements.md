# 总索引精简与响应式调整

日期：2026-11-16

本文记录总索引及其与讲义、知识网络衔接处的界面调整，并说明统计数据的维护方式。

## 标题与简介

- 总索引主标题为“高中生物总索引”。
- 期次上方的品牌文字为“树梢文档”，保留“人教版 2019”标识。
- 简介由动态统计和一句功能说明组成：“支持考点检索、知识网络、语音讲解与连续播放。”
- “使用方法”按钮位于总索引标题区域右上侧，通过 flex 与标题分隔；窄屏也保留在该区域，不覆盖标题。
- 总索引五册表格前不再显示“五册 / 选择一册开始”横标。

## 学科知识网络入口

总索引保留学科知识网络的标题、打开按钮、知识领域和跨册主线入口，不再显示“索引覆盖、概念数、关系数、原文可查数”等统计说明。

知识网络页面内的“覆盖与说明”面板保留，数据校验和整理状态仍可在该面板查看。

## 五册表格

- 删除总时长及各册时长，不显示“时长”列。
- 删除主索引的播放列；点击书名进入相应册的目录。
- 五册书名下保留章节目录，移除“讲义已定稿 · ”状态前缀。
- 书名优先完整显示，不因宽度不足逐字换行。空间不足时由表格外层提供横向滚动。
- 各册的章数、期数和考点数由 `SITE` 自动刷新。

## 统计数据唯一来源

`assets/js/site-data.js` 中的 `SITE` 是册、章、期和考点数据的唯一来源。`assets/js/app.js` 启动时计算：

- 全站册数、期数和考点数；
- 每册章数、期数和考点数；
- 每章期数及原有 chapter duration 展示；
- 每期考点数和考点标题清单。

总索引简介、五册汇总表、各册章节统计和每期考点信息均由这些计算结果更新，不再单独维护一组静态总数。`site-data.js` 仍由既有生成流程维护，不在 `app.js` 中另存需要手工同步的总数。

## 播放器显示范围

底部语音播放器只在具体讲义页显示。总索引、本册目录、使用说明和知识网络页面不显示播放器，也不保留底部空白。

进入讲义时恢复播放器及其所需的底部空间；切换页面只控制显示，不因隐藏播放器而主动停止已有音频。

## 顶栏面包屑路径

- 顶栏标题改为 Windows 路径式的可点击面包屑。
- 最左侧使用羊皮纸 SVG 图标代表“树梢文档”，点击返回总索引；图标容器与图标同宽，顶栏左右采用一致的间距。
- 讲义路径依次链接到所属教材、章节和当前期；知识网络显示所属范围及当前焦点；使用方法也有对应位置标识。
- 空间不足时优先省略左侧中间路径并显示省略号，保留根图标和最右侧当前位置；点击省略号返回上一级目录。
- 路径在路由变化、搜索展开或收起以及视口尺寸变化时重新计算。

## 窄屏顶栏与搜索

- 顶栏位置标题始终优先显示，搜索框在剩余空间内收缩；不再只根据固定屏幕断点决定是否折叠。
- 完整搜索框可用宽度不足约 180px 时，无论当前视口宽窄都自动折叠为图标按钮；空间恢复后自动展开完整输入框。
- 顶栏宽度变化时收起手动展开的搜索，避免把旧宽度下的展开状态带入拥挤布局。
- 点击搜索图标展开输入框并自动聚焦，再次点击同一图标收起；展开时通过压缩面包屑为输入框腾出空间。
- 窄屏展开时隐藏输入框内部重复的搜索图标，只保留外部切换按钮。
- `Ctrl K` / `⌘ K` 在折叠状态下也会展开搜索并聚焦输入框。
- 空间充足时保持原有的完整搜索框。

## 验证

需在浏览器中检查总索引的桌面和窄屏布局、使用方法入口、各册章节标题以及顶栏间距。
