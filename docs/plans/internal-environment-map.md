# 「内环境与稳态」导图：十字结构方案

日期：2026-11-25　分支：`mindmap-redesign`　导图：`m-internal`（`#/map/bio/rel/m-internal`，锚点 `xb1-internal`）

## 1. 为什么重做

上一版（提交 `81aee6d`）照搬了细胞呼吸的做法：上半部分是血浆、组织液、淋巴液相互转化的示意图，占了主要位置；下半部分是"内环境稳态"的五个模块。用户反馈：

1. 这一章的逻辑和细胞呼吸不一样。细胞呼吸围绕"物质在各阶段间的转化"展开，所以线粒体示意图是主角；这一章**不是**围绕三种液体的转化展开的。液体的组成是一个大考点，但不是主线。
2. 这一章的主角是**内环境本身**，侧重**功能**：它是细胞与外界环境之间的桥梁，它与两侧不断交换物质，它的状态靠调节维持稳定。
3. 上一版上半部分（组成）和下半部分（稳态）几乎没有联动，说明结构不对。
4. 要从头设计结构，不做"呼吸作用的套皮"；可以借鉴教材原框架图（`m-homeostasis`）；实现技术（模块、关联、示意图、视口适配等）沿用现有框架。

教材原框架图的骨架是一个闭环：组织细胞 ⇄ 内环境 ⇄ 外界环境（四个系统参与）；内环境 → 稳态 →"为细胞代谢的正常进行提供各种物质和条件"→ 回到组织细胞；稳态靠神经、体液、免疫调节。讲义 XB1-01 p9 的图也是这个结构。新方案把这个闭环作为主干。

## 2. 结构：十字

内环境在正中，两条轴在它身上交叉：

- **横轴 = 桥梁**（内环境在做什么）：外界环境 ⇄ 四个系统 ⇄ 内环境 ⇄ 细胞。
- **纵轴 = 稳态**（内环境怎样保持稳定、稳定了有什么用）：调节网络 → 内环境的状态 → 稳态 → 意义（回到细胞）／失调。

内环境的**状态**（化学成分、渗透压、酸碱度、温度）画在内环境区域**里面**——稳态不是另一块内容，而是"这几项保持相对稳定"。这样两条轴共用同一组节点，上下、左右自然联动。

```
                          [神经—体液—免疫调节网络 ＋]
                            │调节                 ╲ 各器官、系统协调活动（指向四个系统）
                            ▼
[外界环境] ⇄ [四个系统 ＋] ⇄ ┌─────────── 内环境（细胞外液） ───────────┐ ⇄ [细胞 ＋]
  营养物质、O₂ →             │          [组成：血浆 · 组织液 · 淋巴液 ＋]      │   养料、O₂ →
  ← CO₂、代谢废物            │ [化学成分 ＋] [渗透压 ＋] [酸碱度 ＋] [温度]   │   ← 代谢废物、CO₂
                            └──────────────────────────────────┘
                            │ 成分和理化性质保持相对稳定
                            ▼
[失调与疾病 ＋] ←超过调节限度— [内环境稳态 ＋] —正常生命活动的必要条件→ [意义 ＋] ─→（箭头回到"细胞"）
[易错点 ＋]
```

默认可见约 14 个框：外界环境、四个系统、内环境（区域标题或主节点）、组成、化学成分、渗透压、酸碱度、温度、细胞、调节网络、内环境稳态、意义、失调与疾病、易错点。

读法：
- 横着读：细胞通过内环境与外界环境交换物质——"内环境是细胞与外界环境进行物质交换的媒介"。
- 竖着读：调节网络让内环境的成分和理化性质保持相对稳定——这就是稳态。
- 闭环：稳态 → 意义 → 细胞（细胞代谢需要适宜的条件）；细胞 → 内环境（细胞也参与内环境的形成和维持，讲义 XB1-01 p9）。

### 示意图（底图）

只做"桥"的示意，不画血管和淋巴管：
- 内环境：一块浅色区域（`art` 的 `rect`，`kind: 'tissue'`），标"内环境（细胞外液）"。状态节点和组成节点都在里面。
- 细胞：右侧一个椭圆（`kind: 'cell'`），标"细胞（细胞内液）"。
- 外界环境可不画底图，或用一块虚线区域；以清楚为准。
- 节点用 `at` 指向所在区域，选中时区域加深（现有功能）。

组成（血浆、组织液、淋巴液）不再有专门的血管、淋巴管底图。

## 3. 模块（点带 ＋ 的展开）

| 开关 | 展开内容 | 讲义 |
|---|---|---|
| 四个系统 `sys` | 消化系统：营养物质进入；呼吸系统：O₂ 进入、CO₂ 排出；泌尿系统、皮肤：代谢废物排出；循环系统：运输。四个系统也是"直接参与维持内环境稳态的系统"。附：O₂ 从外界进入组织细胞并被利用至少穿过 11 层生物膜 | xb1-01/p9、xb1-02/p3 |
| 组成 `parts` | 展开后把"桥"画细：血浆、组织液、淋巴液三个节点排在横轴上——血浆靠系统一侧（循环系统运输的就是它），组织液靠细胞一侧（与细胞内液双向交换），淋巴液在两者之间偏下；血浆 ⇄ 组织液（双向）、组织液 → 淋巴液（单向）、淋巴液 → 血浆（单向）、组织液 ⇄ 细胞。另有：体液的比例（细胞内液约 2/3、细胞外液约 1/3）、血浆成分的特点（蛋白质含量明显较高） | xb1-01/p1、p2、p5 |
| 细胞 `cells` | 细胞生活的内环境：组织细胞→组织液；血细胞→血浆；淋巴细胞→淋巴液、血浆；毛细血管壁细胞→血浆、组织液；毛细淋巴管壁细胞→淋巴液、组织液。"细胞参与内环境的形成和维持" | xb1-01/p3、p9 |
| 化学成分 `comp` | 属于内环境的物质；不属于的物质及原因；三问判断法；发生／不发生在内环境中的反应 | xb1-01/p4 |
| 渗透压 `osm` | 取决于溶质微粒数目；血浆主要与无机盐、蛋白质有关；细胞外液 90% 以上来自 Na⁺、Cl⁻；0.9% NaCl 等渗；组织水肿的五种成因（分"血浆渗透压↓"和"组织液渗透压↑"两类） | xb1-01/p6、p10 |
| 酸碱度 `ph` | pH 7.35～7.45；缓冲物质 HCO₃⁻、H₂CO₃；乳酸 + NaHCO₃ → 乳酸钠 + H₂CO₃ → CO₂ 经呼吸排出；模拟生物体维持 pH 稳定的实验 | xb1-01/p7、xb1-02/p1 |
| 温度 | 不设模块，37 ℃左右写在节点上 | xb1-01/p8 |
| 调节网络 `mech` | 贝尔纳（神经系统）→ 坎农（神经调节和体液调节，提出"稳态"）→ 现在的神经—体液—免疫调节网络；调节能力有一定限度（外界变化过于剧烈或自身调节功能出现障碍，如高原反应） | xb1-02/p2、p3、p4 |
| 内环境稳态 `steady` | 定义；相对稳定＝动态平衡（成分和理化性质在一定范围内波动）；稳态概念的发展（分子、细胞、器官、群体各层次都有稳态） | xb1-02/p2、p7 |
| 意义 `sig` | 正常生命活动的必要条件：酶的活性 ← 适宜的温度和 pH；细胞呼吸供能 ← 血糖和 O₂ 稳定供应 | xb1-02/p6 |
| 失调与疾病 `dis` | 每种失调一条，并各自连到对应的状态节点：血糖过低→低血糖；尿素等不能排出→尿毒症；Ca²⁺ 过低／过高→抽搐／肌无力（成分）；pH→酸中毒、碱中毒；体温→发烧、中暑；渗透压→细胞吸水或失水 | xb1-02/p5 |
| 易错点 `warn` | 沿用上一版的 9 条（消化液等不属于体液；内环境不含细胞内液；识图找淋巴液；管壁细胞两侧写全；血红蛋白不属于内环境；稳态≠恒定；调节能力有限度；稳态不只存在于内环境；自来水组、缓冲液组都是对照组） | 各处 |

可选的"其他模块"节点（`s: 'ext'`）：体温调节（xb1-12/p4）、水和无机盐平衡的调节（xb1-12/p6）、血糖调节（xb1-10/p3），分别挂在温度、渗透压、化学成分的细节里，表示"具体怎样调节见后面的章节"。落点已核对存在。

模块细节的位置：状态节点的细节向下展开（在内环境区域下方预留各自的列），系统、细胞、调节网络的细节在各自一侧展开。必须保证"全部展开"后互不重叠（上一版用脚本按行数排列各列，可复用 `scratchpad/gen_internal.py` 的做法，但最终数据要写进 `knowledge-network-data.js`，可手工维护）。

## 4. 关联（`rel`）：让两条轴联动

这是本方案的重点。每个节点的关联要回答"它在桥上起什么作用、和稳态有什么关系"，不是罗列相邻节点。

**四个状态节点（化学成分、渗透压、酸碱度、温度）统一回答四个问题，按这个顺序：**

1. 由什么决定（组成／来源）
2. 怎样维持（沿"桥"画路线 `trace`，并指向调节网络或"其他模块"节点）
3. 失调会怎样（指向"失调与疾病"里对应的那一条）
4. 为什么重要（指向"意义"里对应的那一条）

例：点"酸碱度"——
- 路线：细胞（产生乳酸、CO₂）→ 酸碱度（缓冲物质中和）→ 四个系统（呼吸系统）→ 外界环境（CO₂ 排出）。
- 关联：缓冲物质 HCO₃⁻、H₂CO₃（由什么决定）；乳酸 + NaHCO₃ 的反应（怎样维持）；酸中毒、碱中毒（失调）；酶的活性需要适宜的 pH（意义）；模拟实验（实验）。

例：点"渗透压"——无机盐、蛋白质（决定）；水和无机盐平衡的调节（维持，其他模块）；组织水肿、细胞吸水或失水（失调）；0.9% NaCl 等渗（应用）。

**桥上的节点回答"它影响内环境的哪几项状态"：**

- 四个系统：消化→化学成分（营养物质）；呼吸→酸碱度（排出 CO₂）、化学成分（O₂）；泌尿→化学成分（代谢废物）、渗透压（水和无机盐）；并注明"直接参与维持稳态"（指向稳态）。
- 细胞：从内环境获得养料、O₂（化学成分）；向内环境排出代谢废物、CO₂（影响化学成分、酸碱度）；依赖稳态（意义）；参与内环境的形成和维持。
- 外界环境：路线 外界环境 → 四个系统 → 内环境 → 细胞；外界变化过于剧烈会破坏稳态（指向调节能力有限度、失调）。

**纵轴节点：**

- 内环境稳态：范围框（`scope`）把四个状态节点框起来，写"稳态 = 这几项保持相对稳定"；靠什么（调节网络、四个系统）；为什么重要（意义）；不稳定会怎样（失调）；易错（≠恒定不变、调节能力有限度）。
- 调节网络：范围框框住四个状态节点；通过各器官、系统协调活动（四个系统）；有限度（失调）。
- 意义：路线 稳态 → 意义 → 细胞；分别指向温度、酸碱度（酶活性）和化学成分（血糖、O₂）。
- 失调与疾病的每一条：`dir` 箭头从对应状态节点指过来，线上写"过低""过高""失调"等。

**组成模块：**

- 血浆：循环系统运输的是血浆（指向四个系统）；蛋白质多→渗透压；血浆渗透压降低→组织水肿；缓冲物质在血浆中。
- 组织液：细胞直接生活的环境（指向细胞）；组织液增多＝水肿。
- 淋巴液：路线 组织液 → 淋巴液 → 血浆；淋巴循环受阻→水肿；识图口诀。

所有"为什么"以讲义原文为准；讲义没有直接写、按常规解释补写的，在交付说明里逐条列出。上一版 `m-internal` 里已经写好的关联原因可以直接搬用（见 `git show 81aee6d`）。

横向的两条交换线（外界 ⇄ 系统、内环境 ⇄ 细胞）各画成一去一回两条带标签的箭头（去：营养物质、O₂／养料、O₂；回：CO₂、代谢废物），`k: 'flow'`。

`ortho` 区域设为内环境区域，区域内两端都在里面的关联线走圆角直角线。

## 6. 验收

- 默认视图：一眼看到十字——横向是 外界环境 ⇄ 系统 ⇄ 内环境 ⇄ 细胞，纵向是 调节网络 → 内环境 → 稳态；三种液体不抢眼（只是内环境里的一个"组成"入口）。
