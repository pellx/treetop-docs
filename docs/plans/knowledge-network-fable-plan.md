## 四、点击与导航规则

统一的心智模型：**第一次点是看一眼，第二次点是走进去。** 有子集就展开子集，没有子集就进正文。

| 操作 | 结果 | 重排 | 进历史 |
|---|---|---|---|
| 单击节点 | 选中：高亮它和它的关系线，信息卡显示摘要 | 否 | 否 |
| 再击已选中的分支（或双击、Enter、卡片"聚焦"） | 聚焦：它成为焦点，子集展开，主干收成来路 | 是 | 是 |
| 再击已选中的叶子 | 只有一个讲义目标时进入正文；多个目标时不跳，卡片列出让你选 | 否 | 进正文时是 |
| 点节点右缘"▸n" | 原地展开或收起下一层，不换焦点 | 局部 | 否 |
| 点来路或面包屑上的祖先 | 聚焦到该祖先 | 是 | 是 |
| Esc 或"上一级" | 先关信息卡，再回上一级，顶层回总览 | 是 | 是 |
| "总览" | 回本视图总览 | 是 | 是 |
| 点关系端口 | 先选中对端并预览，再击才跳过去聚焦 | 否，再击是 | 否，再击是 |
| 浏览器后退／前进 | 逐步撤销或重做"聚焦、切视图、进正文" | — | — |
| 导图内搜索（`/`） | 列出匹配节点；回车后聚焦其所在分支并选中 | 是 | 是 |
| 顶栏全站搜索（Ctrl/⌘K） | 维持现状，搜讲义 | — | — |
| 滚轮 | 画布纵向滚动，不缩放 | — | — |
| 拖动空白 | 仅画布溢出时平移 | — | — |
| 拖动节点 | 不支持 | — | — |

**三档的分工**
- 选中：用来判断"是不是我要找的、它连着什么"，零成本。
- 聚焦：用来看子集，代价是一次重排，随时可退。
- 进正文：只有三个入口，卡片里的"打开讲义"、再击叶子、键盘 Enter。

**返回导图**
- 进正文后，顶栏标题旁出现"← 返回导图"。
- 回来时视图、焦点、选中、展开、滚动位置和信息卡全部恢复。
- 刚看过的节点带一个"已看"标记，仅本次会话有效，方便接着往下看。

**键盘**（仅当焦点在导图内）
- ↑↓ 在同级间移动，→ 进子级，← 回父级，Enter 等于"再击"。
- `1/2/3` 切视图，`0` 回总览。
- 空格始终留给播放器。

## 五、重排布局规则（确定性）

布局是一个纯函数：输入视图数据、焦点、展开集和视口宽度，输出每个节点的坐标。同样的输入永远得到同样的画面。

1. **总览**：根在中间，一级分支按数据顺序分到左右两翼（右侧自上而下，再左侧自下而上），显示到第二层。节点宽度按层级固定，标签不超过 12 个字，所以不需要测量文字。
2. **聚焦**：焦点固定在画布左中。
   - 祖先压成左侧"来路"链，每个只留名字和"+n 同级"。
   - 焦点的子集向右展开，再下一层按需展开。
   - 其他分支隐藏。
   - 选这个方向约定而不保留原来的左右翼，是因为"左是来路、右是更深"比绝对方位更容易学会。
3. **方位靠顺序保持**：同级节点的上下顺序在任何状态下都不变。面包屑和来路随时告诉你在哪。
4. **关系线不参与布局**：因果、类比、对比这些边只在选中节点时画出。对端不在画面里时，在画布边缘停一个"端口"小牌，写明对端名称和所在分支。这样不会出现毛线团。
5. **多父节点**：每个视图里一个节点只有一个本体位置。别处需要它时放"↗ 引用"小牌，虚线框，点了选中本体。第 2 讲"生物膜系统"的虚线汇聚就是这个思路。
6. **环**：树边由视图定义，加载时校验无环、单父。第 8 讲那种生命周期环、负反馈环属于关系边。任务视图里的循环过程排成一行，末尾标"↺ 回到第 1 步"，不画闭合圆。
7. **跨集合边**：对端属于别的集合时，端口上写集合名。首版只显示不跳转，第二阶段才能进入。
8. **"显示更多"**：一个父节点的子项超过 7 个时，先显示前 6 个加"显示更多（+n）"。先后由数据顺序决定，作者把核心放前面。原地展开，不换焦点。
9. **动画**：
   - 被点的节点是锚，从原位移到焦点位。子集跟着展开，无关分支淡出，新出现的层最后淡入，全程约 260ms。
   - 连续点击时，状态立即更新到最新目标，每个节点从当前位置过渡到新目标，不排队。
   - 旧一轮的延迟淡入用代次号作废。
   - 系统开启"减弱动效"时改为直接切换，沿用 `site.css:579` 的做法。

## 六、三种视图，同一批节点

概念节点只定义一次，包括名称、摘要、讲义位置和证据。视图只提供摆法和本视图里的备注。

| 视图 | 骨架（参与布局） | 叠加显示 | 分组的含义 |
|---|---|---|---|
| 知识关系 | 归类／组成，如"为什么变→生物因素→捕食者与猎物曲线" | 影响／决定、实例—属于、对比／易混 | 知识上谁属于谁 |
| 大题任务 | 步骤先后，如"估数量→判趋势→找原因→定措施→说意义" | 每步用到的概念，以及这一步怎么写 | 做题时第几步用到 |
| 推导方法 | 方法组，一个组是一种推法 | 组内成员互为"同一推法" | 推理结构相同，与章节和归类无关 |

**关系类型**分开存，画法也分开：

| 类型 | 画法 | 参与布局 |
|---|---|---|
| 归类／组成 | 实线肘形 | 知识关系视图 |
| 先后 | 箭头 | 大题任务视图 |
| 影响／决定 | 箭头加关系词 | 否 |
| 依据／实例 | 关系词 | 否 |
| 对比／易混 | 双向虚线 | 否 |
| 同一推法 | 方法组框 | 推导方法视图 |
| 相互 | 双箭头 | 否 |

"侧面"（特点／作用／应用这类占位）不单独成关系。站内有对应考点的，变成真叶子；没有的，并进信息卡。

**切换规则**
- 保留当前选中的概念和信息卡。
- 目标视图里有它，就直接聚焦到它所在的步骤或方法组。
- 没有，就回目标视图总览并提示"此节点不在该视图中"，信息卡不丢。
- 每个视图各自记住展开和滚动位置。
- 切视图算一步历史。
- 信息卡的"也出现在"是主要的切换入口，例如"任务：防治方案 · 第 4 步""方法：负反馈链"。

## 十、接入现有站点

**文件**
```
assets/js/map.js            布局、渲染、状态（新增）
assets/js/map-data-xb2.js   window.MAP_DATA，手工维护（新增）
assets/css/map.css          只引用 site.css 已有颜色变量（新增）
index.html                  加 1 个 link、2 个 script
assets/js/app.js            route() 加 map 分支、spy 守卫、暴露极小接口
```

- 数据用 JS 全局变量，不用 `fetch` 读 JSON。原因是站点支持直接本地打开，现有三份数据也是这个方式。
- 数据不放进 `site-data.js`，它的首行注明"由 build.py 生成，请勿手改"。
- 侧栏"知识网络"入口和顶栏返回按钮由 `map.js` 运行时插入，做法同 `app.js:48–58` 插入主题按钮，避免手改生成的 HTML。

**路由**：`#/map/<集合>/<视图>/<节点>`，例如 `#/map/pop/rel/biotic`。
- 现有 `route()` 按 `/` 拆分，在 `app.js:707` 查期号之前加一个 `head === 'map'` 分支即可。
- 节点是叶子时，聚焦其父并选中它。
- 旧缓存的 `app.js` 遇到这个地址会落回总索引（`app.js:708`），不会报错。

**状态分工**

| 载体 | 存什么 |
|---|---|
| hash，新增历史 | 集合、视图、焦点 |
| sessionStorage `tt-map:<集合>` | 选中、各视图展开集、滚动位置、信息卡开合、本次已看节点 |
| sessionStorage `tt-map-return` | 离开导图时的地址和之后的跳转次数 |
| localStorage | 只存偏好，如上次用的视图 |
| history.state | 不用 |

**正文滚动改地址的处理**
- 滚动时 `app.js:734–739` 用 `replaceState(null, …)` 改写的是讲义那一条历史，导图那条不受影响。所以从导图直接进正文后，后退必然回到导图。
- 它同时把 `history.state` 清成 null，所以返回凭据必须放在 sessionStorage。
- "返回导图"按钮：离开导图后只发生过一次跳转时走 `history.back()`，否则直接前往保存的导图地址。

**直接打开、刷新、新标签**
- 地址里的集合、视图、节点足以重建画面，其余取默认值。
- 节点不存在：回该视图总览并提示。
- 视图不存在：用"知识关系"。
- 集合不存在：回导图首页。
- 新标签打开的讲义没有返回凭据，顶栏改显示"在导图中定位"，按"讲义锚点→概念"的反查表进入。

**从代码里查到、必须处理的五件事**
1. **迟到的滚动消息**：从正文退回导图后，隐藏的 iframe 仍可能发来 spy 消息，`app.js:735` 只比对期号，会把地址栏改回讲义地址。需要加"iframe 隐藏时忽略"的判断。
2. **跨期自动翻页**：`app.js:623` 在音频跨期时会自动翻到下一期。导图显示时要像 `showHome` 那样把 `frameKind` 置空（`app.js:670`），否则听着音频看导图会被带走。
3. **空格键**：外壳里空格被全局拦截且不触发按钮（`app.js:436–443`），所以导图节点只能用 Enter 激活。
4. **方向键**：外壳总会接管方向键。导图在自己的容器上先处理并 `preventDefault`，外壳的处理函数检查 `defaultPrevented` 后会自动让开（`app.js:433`）。焦点不在导图里时，方向键仍是上一句／下一句。
5. **Esc**：手机抽屉目录打开时，Esc 先关目录（`app.js:306`），导图不抢。

**渲染**
- 原生 JS，节点是绝对定位的 `<button>`，连线是一层 SVG 折线。不引入任何库。
- 理由：同屏节点不超过 60 个；文字、焦点、无障碍和主题都是 DOM 的强项；固定行高的树布局本身很小。
- 播放器、目录、全站搜索代码不动。快照里没有 `search-data.js`，导图搜索用自己的节点索引。

## 十二、验收标准

1. **找节点**：从总览出发，不用搜索，3 次点击内到达任一叶子；用导图搜索时，输入名称后回车即到。
2. **精确跳转**：27 个叶子的每个讲义目标都落在对应考点标题处；多目标节点不自动跳。
3. **返回恢复**：进正文、滚过两个考点、点"返回导图"或按后退，视图、焦点、选中、展开和滚动位置与离开时一致；地址栏是导图地址，等 1 秒后不被改写。
4. **多视图**：选中"捕食者与猎物曲线"后切到任务和方法视图，它保持选中并可见；切回后原视图的展开状态还在。
5. **快速连点**：1 秒内连续点 5 个不同节点，最终画面等于只点最后一个的结果，没有残留或重叠节点；后退逐步可逆。
6. **确定性**：同一地址在刷新、换主题、改窗口宽度后再改回时，节点位置相同。
7. **信息密度**：1366×768、目录展开时，聚焦态能同屏显示不少于 15 个节点，字号不小于 14px，无重叠，无横向滚动条。
8. **手机**：390px 宽度下完成"总览→聚焦→摘要→进正文→返回"，抽屉不遮播放器，无横向滚动。
9. **键盘**：只用键盘走完同一流程；焦点在导图外时，空格和方向键仍控制播放器。
10. **播放器**：播放中进出导图不中断；音频跨期时不把人带离导图。
11. **主题与样式**：深浅主题切换即时生效，对比度不低于 4.5:1，所有边框为直角；系统减弱动效时没有位移动画。
12. **离线与子路径**：本地直接打开 `index.html`，以及部署在 `/treetop-docs/` 子路径下，都能用；没有任何外部请求。
13. **坏链接**：人为把一个目标改成不存在的期或越界序号，页面不报错，卡片显示"位置可能已变动"，控制台列出问题项。
14. **证据缺失**：没有记录的节点显示"暂无记录"；全站不出现百分比或"高频"字样。
15. **来源可查**：每条关系在卡片里能看到依据（参考图讲次、讲义锚点或"编辑判断"）。

**内容验证边界**：骨架已对照第 17、18 讲图，细节已对照讲义原文。三样东西没有外部依据，上线前需要你用真题校正：跨章节的关系边、任务视图的步骤划分、方法视图的类比分组。
