# 知识关系图：先主干、点击再深入（方案）

日期：2026-11-25　分支：`mindmap-redesign`　试点导图：`m-resp` 细胞呼吸（`#/map/bio/rel/m-resp`）

## 1. 要解决的问题

上一版把细胞呼吸的 40 多个知识点一次全部画出，并在鼠标悬停时突出联系。用户反馈：

1. **太闪**：鼠标在画面上移动，聚焦对象不断切换，整张图不停明暗变化。
2. **没有重点**：一进来就是全部细节，看不出主干。主干应该是"三个阶段 → 按进行程度分成有氧呼吸和无氧呼吸"；产物、反应式等是挂在主干上的细节。
3. **易错点分散**：它们与结构关系不大，应集中在一处，默认隐藏；点某一条时再在图上标出它讲的是哪里。

总要求：**优先展现清晰的结构，通过点击逐步得到深入的信息。**

## 2. 交互方案

| 项目 | 做法 |
|---|---|
| 聚焦 | 悬停只改变边框颜色，不让其他内容变淡。**点击**知识点才选中：与它直接相连的线和点保持原色，其余变淡。点空白处（非拖动）、按 Esc 或点顶栏 × 取消 |
| 讲义入口 | 选中后画布**顶部出现一条栏**：知识点名称、一句说明（`tip`）、"读讲义 ›"按钮（带期号与考点名）、有细节时的"展开细节 / 收起细节"、×。未选中时显示一行提示。栏右侧固定有"全部展开 / 全部收起" |
| 默认视图 | 只显示主干（没有 `in` 的节点和它们之间的线） |
| 展开 | 带 ＋ 的知识点是开关（`open`）：第一次点击展开它的细节并选中；已选中时再点收起；展开着但未选中时只选中。展开不重排，细节出现在预留位置；视口在需要时平移到看得见 |
| 易错点 | 集中为一个模块，默认收起。点其中一条：自动展开它涉及的模块，在图上标出相关知识点（`marks`），从这条易错点向它们画**临时连线**，顶栏显示讲解 |
| 跨区联系 | 不再常驻画出长虚线，统一改为 `marks`：点选时才画临时连线（如点"酒精的检测"才指向"酒精"） |
| 图例 | 默认折叠成"图例"两个字，点开才显示 |
| 状态 | 展开的模块和选中项随地址存入 `sessionStorage`，从讲义"回到思维导图"时恢复 |

其余 19 张导图没有模块，但统一成"点击选中 → 顶栏读讲义"，不再点击即跳转。

## 3. 数据格式（`KN_DATA.maps`）新增字段

| 字段 | 位置 | 含义 |
|---|---|---|
| `open: '模块名'` | 节点 | 该节点是模块开关，右侧显示 ＋ / － |
| `in: '模块名'` 或数组 | 节点、连线、分组、独立文字 | 只在所列模块之一展开时显示。连线另外要求端点都可见；分类括线的主干要求上级可见且至少一个下级可见 |
| `marks: [节点 id…]` | 节点 | 选中时标出的相关知识点（画临时连线）；对象在收起的模块里时先展开该模块 |
| `d: '副标题'` | 节点 | 第二行小字（如阶段的场所） |
| `tip` | 节点 | 顶栏里的一句说明（已有字段，现在主要在顶栏显示） |
| `s: 'mod'` | 节点 | 模块入口的样式（加粗、稍粗边框） |

保留上一版的：`s: sub/detail/warn/eq/ext`、分组 `style: 'zone'`、连线 `k: flow/link/apply/contrast/ext`。

## 4. `m-resp` 的内容设计

### 4.1 主干（默认可见）

```
                         ┌─ 有 O₂ → [第二阶段·线粒体基质] → [第三阶段·线粒体内膜]     ← 与"有氧呼吸"同一行
[细胞呼吸] ┬ [有氧呼吸] ┐│
           │            ├ [第一阶段·细胞质基质] ┤
           └ [无氧呼吸] ┘│  （两种类型的第一阶段相同）
                         └─ 无 O₂ → [第二阶段·细胞质基质]                            ← 与"无氧呼吸"同一行

[探究实验 ＋]   [比较·判断·计算 ＋]   [影响因素与应用 ＋]   [易错点 ＋]      ← 由"细胞呼吸"向下引出的四个模块入口
```

- 阶段节点用 `d` 写场所；`tip` 写这一步的要点。
- "有氧呼吸""无氧呼吸"与各自的阶段在同一水平行上，行对齐表达"由哪些阶段构成"。
- 主干只有 6 个阶段/类型节点、1 个中心、4 个入口，共 11 个框。

### 4.2 阶段细节（点阶段展开）

物质节点放在阶段之间的箭头上（节点不透明，盖在线上，读作"阶段 → 物质 → 阶段"）；额外反应物从上方进入，能量写在下方。

| 开关 | 展开内容 |
|---|---|
| 第一阶段 `s1` | 葡萄糖（上方进入）；丙酮酸 + [H]（在通往第二阶段的主干线上，`in: ['s1','a2','n2']`）；少量能量 |
| 有氧第二阶段 `a2` | H₂O（上方进入）；CO₂；[H]（在通往第三阶段的线上，`in: ['a2','a3']`，`tip`：含第一阶段产生的 [H]）；少量能量 |
| 第三阶段 `a3` | O₂（上方进入）；H₂O（右侧产物）；大量能量 |
| 无氧第二阶段 `n2` | 酒精 + CO₂（实例：酵母菌、多数植物细胞如水淹的根）；乳酸（实例：乳酸菌、动物骨骼肌、马铃薯块茎、甜菜块根、玉米胚）；不释放能量 |

物质节点没有连线直接连到阶段时，用 `marks` 互相关联，保证选中阶段时它们不被变淡。

### 4.3 类型细节（点"有氧呼吸""无氧呼吸"展开）

- 有氧呼吸 `aer`（放在有氧一行的上方）：总反应式；1 mol 葡萄糖释放 2870 kJ、约 977 kJ 存入 ATP、其余为热能 → 指向"ATP"（其他模块，`s: 'ext'`，落点 bx1-16/p3）；追踪氧元素。
- 无氧呼吸 `an`（放在无氧一行的下方）：两条反应式；约 61 kJ 存入 ATP，大部分能量留在酒精或乳酸中。

### 4.4 四个模块

| 入口 | 内容（讲义落点） |
|---|---|
| 探究实验 `exp` | 酵母菌：兼性厌氧菌；装置（NaOH、无氧组先放置）；对比实验；产物检测（CO₂：石灰水、溴麝香草酚蓝；酒精：酸性重铬酸钾）。`marks`：酒精检测 → 酒精 + CO₂；CO₂ 检测 → CO₂、酒精 + CO₂；酵母菌 → 酒精发酵实例（bx1-17/p1–p3） |
| 比较·判断·计算 `judge` | 有氧与无氧的比较（`marks` 两种类型和第一阶段）；按气体变化判断呼吸方式；计算比例（`marks` 反应式）（bx1-18/p3–p5） |
| 影响因素与应用 `use` | 温度、水、CO₂、O₂ 四个因素 → 储存果蔬与种子；O₂ → 包扎伤口、酿酒、松土、有氧运动、稻田排水。`marks`：酿酒 → 酒精；有氧运动 → 乳酸；稻田排水 → 酒精（bx1-18/p6–p7） |
| 易错点 `warn` | 见下 |

### 4.5 易错点（每条一个 `warn` 节点，`tip` 写讲解，`marks` 写涉及的知识点）

1. 线粒体不能直接分解葡萄糖，进入线粒体的是丙酮酸 → 葡萄糖、第一阶段、丙酮酸、有氧第二阶段（bx1-17/p7）
2. 能否有氧呼吸看有无相关的酶，不能只看有没有线粒体；原核生物（醋酸菌、蓝细菌）也能有氧呼吸 → 有氧呼吸、有氧第二、第三阶段（bx1-17/p7）
3. 哺乳动物成熟红细胞无线粒体，只进行无氧呼吸 → 无氧呼吸、乳酸（bx1-17/p7）
4. 无氧呼吸只在第一阶段释放少量能量 → 第一阶段、无氧第二阶段及两处能量（bx1-18/p1）
5. 人体骨骼肌无氧呼吸产生乳酸，不产生 CO₂ → 乳酸及其实例（bx1-18/p2）
6. 葡萄糖也能使酸性重铬酸钾变色，要适当延长培养时间 → 酒精检测、酒精（bx1-17/p2）
7. 对比实验没有单独的空白对照组 → 对比实验（bx1-17/p3）
8. 底物是脂肪时 O₂ 消耗量 > CO₂ 释放量，不能直接套用 → 判断呼吸方式（bx1-18/p4）

所有文字以讲义原文为准（`biology/required-1/bx1-17.html`、`bx1-18.html`），不新增讲义之外的结论。

### 4.6 版面

主干在上（约 1340 × 260），四个入口排成一行在主干下方，各自的内容在入口正下方纵向展开，四列互不重叠。类型细节预留在主干上方和下方的空行。默认视口对准"当前可见内容"，所以收起时画面紧凑。
