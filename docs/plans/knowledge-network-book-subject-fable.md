# 全书＋学科级智能索引：思维导图怎样呈现（第三轮讨论稿）

本稿只讨论怎样表现、怎样使用、怎样与现有站点共存。三类说法分开标：**需求**是你明确说过的；**推荐**是我的建议，都可以改；**待验证**要在原型里比较后才定。

本轮只补查了五册 104 期的标题和部分考点标题。必修1、必修2、选必1、选必3 的讲义正文不在快照里，涉及它们的例子只以考点标题为据，引文只来自选必二。

## 一、结论先说

1. **产品是一张网，不是多张图。** 学科图、五张全书图、局部子网络，都是同一批节点在不同范围下的呈现。数据只有一份。
2. **两条轴互不替代。** 一条是查看范围（学科／一本书／局部），一条是组织逻辑（知识关系／大题任务／推导方法）。任何范围下都能切逻辑，任何逻辑下都能换范围。
3. **覆盖分两种，分开标。** "索引覆盖"从第一天起就是五册全部考点。"关系已整理"按批增加，界面上如实显示比例。
4. **上一版的 33 节点集合降级为一个"跨章专题"。** 它由 1 个根、5 个分组、27 个知识节点组成，其中有的知识节点自己还有下级。它是完整产品里的一个部件，不是另起的小架构。
5. **接入要节制。** 网络是外壳里的一种页面，另外在总索引、本册目录、讲义顶栏各放一个小入口。原目录、搜索、播放器、讲义页都不动。

## 二、一张网，两条轴

### 范围 × 逻辑

| 范围 | 知识关系 | 大题任务 | 推导方法 |
|---|---|---|---|
| 学科 | 约 8 个领域向外发散；跨册联系聚合成几条"主线" | 任务清单按领域分组，跨册任务有标记 | 方法组清单，成员来自各册 |
| 一本书 | 本册的部分→单元→概念；跨章专题另成一组 | 本册的任务 | 有本册成员的方法组，外册成员带册名 |
| 局部（聚焦某节点） | 它的子集和逐条关系 | 用到它的任务及所在步骤 | 它所在的方法组和同组成员 |

### 层级与两种覆盖（推荐）

| 层 | 是什么 | 数量级 | 怎么来 |
|---|---|---|---|
| 范围根 | 学科、五册 | 6 | 固定 |
| 领域 | 学科图第一圈 | 约 8 | 人工，一次定 |
| 部分 | 全书图第一圈，接近"章"的粒度，按知识命名 | 约 25–30 | 人工，一次定，并登记它管哪些期 |
| 单元 | 一组紧密相关的知识，可跨期 | 约百个 | 人工分批；未整理时自动用"期"顶替 |
| 概念 | 稳定的知识点，可挂多个讲义位置 | 整理后才有数 | 人工分批；未整理时自动用"考点"顶替 |
| 讲义位置 | 现有考点锚点 | 732 | 站点已有 |
| 专题 | 跨章或跨册的复习问题集合，成员是引用 | 逐步增加 | 人工 |

- **考点数不等于概念数。** 一个概念可以有多个讲义位置：必修2 `bx2-24/p3`"生物多样性三层次"和选必2 `xb2-14/p1`"三个层次"讲的是同一件事。一个考点也可以拆成多个概念：`xb2-03/p6`"防治与渔业"至少含防治和渔业两个。
- **索引覆盖**靠"每一期登记到一个部分"保证。某个部分还没人工整理时，它下面自动按"期→考点"列出，样式更素，标"按讲义顺序 · 未整理关系"。这样五册从第一天起就完整，而且不比目录少任何东西。
- **关系已整理**只统计人工核对过的概念和边。每个容器节点上写明，如"3 单元 · 22 考点 · 已整理 8"。

### 学科图怎样不变成"五本封面围一圈"（推荐，非唯一分法）

第一圈按知识领域切，不按册。册名只作来源标签和范围切换。领域顺时针按生命系统的尺度由小到大排，位置本身就有含义。站内 `bx1-01/p6`"生命系统结构层次"正是这条线索。

| 领域 | 现有内容 |
|---|---|
| 细胞的物质与结构 | 必修1 第 1–4 章 |
| 细胞的代谢与能量 | 必修1 第 5 章 |
| 细胞的增殖与生命历程 | 必修1 第 6 章，与必修2 减数分裂相接 |
| 遗传的规律与分子基础 | 必修2 第 1–4 章 |
| 变异与进化 | 必修2 第 5–6 章 |
| 个体的稳态与调节 | 选必1 全册 |
| 种群、群落与生态系统 | 选必2 全册 |
| 生物技术与工程 | 选必3 全册 |

这样切，多数领域仍落在一本书内，这是教材本来就按主题编的结果。学科图真正多出来的东西是**主线**：穿过多个领域的跨册联系。在学科总览里，主线画成可开关的几条线，像地铁线路。

| 主线 | 站内落点 | 边的含义 | 依据 |
|---|---|---|---|
| 能量 | `bx1-16/p4`、`bx1-20/p2`、`bx1-17/p6` → `xb2-08/p1–p2`、`xb2-10/p2` | 跨尺度对应 | 选必2 原文；必修1 仅标题 |
| 调节与反馈 | `xb1-02/p3`、`xb1-11/p3` → `xb2-03/p4`、`xb2-12/p1` | 类比：调节结构相同，机制不同 | 选必2 原文；选必1 仅标题 |
| 进化与适应 | `bx2-24/p1` → `xb2-04/p7`、`xb2-05/p6`；`bx2-24/p3` 与 `xb2-14/p1` 合为一个概念 | 解释；同一概念 | `xb2-04/p7` 原文"这是协同进化的结果" |
| 技术回扣原理 | 选必3 基因工程 ← 必修2 第 3–4 章 | 应用—原理 | 仅标题，待核 |

主线的条数和取舍是编辑判断，分批补。

## 三、在原网站里看见什么

**推荐的接入形态**：网络是外壳里的一种页面，与总索引、讲义并列，地址形如 `#/map/范围/逻辑/焦点`。左侧目录照常显示，底部播放器照常工作。

选这个形态有三个理由：
- 导图需要宽度，塞进 296px 的侧栏只能做成另一份目录。
- 六个范围共用同一种页面，只需实现一次。
- 原目录始终在旁边，是任何时候都能用的后路。

"在侧栏里做目录／网络切换"和"读讲义时常驻导图"我都不推荐放在前期。

| 场景 | 入口位置与大小 | 与现有内容的关系 |
|---|---|---|
| 生物总索引 | 简介下方、五册表上方加一条约 160px 高的"学科思维导图"条：8 个领域名、几条主线名、"打开"按钮。侧栏"总索引"下加一个链接 | 五册表原样在下方 |
| 本册目录 | 主按钮区加"本册思维导图"；其下一条同样高度的条：本册各部分、跨章专题数、已整理比例。侧栏"本册目录"下加一个链接 | 章节表原样 |
| 正在读讲义 | 顶栏标题旁一个小按钮"网络" | 讲义页零改动；不常驻、不遮正文 |

讲义顶栏的按钮点开是一个小浮层：

```

所在位置   群落 › 群落的结构 › 生态位
也见于     主线：进化与适应
[在本册网络中打开]  [在学科网络中打开]
↩ 回到网络：群落的结构        （仅当这一页确实是从网络打开的）
上次网络位置：学科 › 能量主线   （仅作提示）
```

## 四、逐状态走一遍

网络页顶部固定三样东西，各管一件事：

| 元素 | 回答的问题 | 表现 |
|---|---|---|
| 范围徽标 | 我在看哪张图 | "学科 ▾"或"选必2 ▾"，可切换；侧栏目录跟着范围走 |
| 位置条 | 这个知识在结构里的哪儿 | 从范围根到焦点的一条结构路径；节点有多处位置时显示"共 n 处 ▾"，可换另一条路径 |
| 来路 | 我这次是怎么过来的 | 只记跨枝、跨册、搜索这类跳转，如"↩ 光合作用（必修1）"；浏览器后退按同样的步子退 |

同一个知识从不同入口进来时，位置条显示这次经过的那条路径，同时标"共 n 处"。信息卡把所有位置和所有讲义位置平等列出，不暗示它只有一个父节点。

| 状态 | 看见什么 |
|---|---|
| ① 第一次打开学科图 | 中心"高中生物"，8 个领域向四周发散，每个带"n 部分 · m 考点 · 已整理 x"。主线默认不画，以一排名字放在图下。首次有一行可关的操作提示 |
| ② 进入全书图 | 点范围徽标换成某一册，或在学科图聚焦某领域后选"以本册为范围打开"。中心换成书名，第一圈是本册各部分，另有一组虚线框的"跨章专题" |
| ③ 聚焦跨章知识 | 在选必2 里展开"跨章专题 › 种群数量"。发散图收拢成左侧一条主干，专题向右展开成 5 个分组。成员是引用，带各自的主位置，如"生物因素 · 位于 种群 › 影响因素" |
| ④ 切到其他册的关联节点 | 在选必2 选中"能量流动的输入"，关系里有"跨尺度对应 → 光合作用（必修1）"。单击只是预览。选"前往"后范围自动扩大到学科，顶部提示"范围已由选必2 变为学科"，来路出现"↩ 选必2 · 能量流动的输入" |
| ⑤ 打开讲义 | 在信息卡或选中节点上点"读讲义"。多个讲义位置时列出让你选。正文照常显示，播放不断 |
| ⑥ 返回上次网络 | 点顶栏"回到网络"，或按浏览器后退。范围、逻辑、焦点、选中、展开、滚动都恢复，刚读过的节点带"已读"标记 |

**"浏览器后退"和"回到网络"是两回事（推荐）**
- 后退只按浏览历史走。
- "回到网络"是语义动作：无论中途翻过几期，它总是直接前往保存的网络位置。它不依赖数跳转次数。
- 只有当这一页确实是从网络打开时，按钮才叫"回到网络"；否则叫"在网络中定位"。
- 新标签打开的讲义不继承别的标签的"来路"，最多看到"上次网络位置"的提示。

## 五、视觉与交互怎样处理规模

### 总览—展开—阅读（推荐）

```
总览（发散）                    展开（主干收拢，子集向右）
       领域B   领域C            主干     焦点        子集
  领域A   ╲   ╱   领域D         学科 ─ 生态 ══ [生态系统] ┬ 结构 ▸7
        [学科]                  (+7)   (+0)              ├ 能量流动 ▸13
  领域H   ╱   ╲   领域E                  同级：种群       ├ 物质循环 ▸7
       领域G   领域F                     群落 人与环境     ├ 信息传递 ▸6
                                                         └ 稳定性 ▸6
```

- **总览**保持中心向外。节点是直角矩形，连线规整，第一圈之外只画"数量角标"，不画节点。中心发散和规整连线可以并存。
- **展开**时，整张发散图收拢成左侧一条主干：根、各级祖先各一个小牌，当前层的同级按原顺序排成一列，可以横向换。被选的分支向右展开，最多两层。这正是你最初设想的"网络移到一侧并折叠"。
- **阅读**是离开网络进正文，靠"回到网络"回来。
- **待验证**：另一种做法是每次聚焦都让焦点重新居中、仍然四周发散。它形态统一，但叶子多时放不下文字。原型里拿这两种做对比。

### 点击（推荐，细节待验证）

- 单击是选中，只出信息卡，不动布局。
- 展开和阅读各有明确控件：选中的节点旁浮出"展开 ▸"和"读讲义 ›"，信息卡上有同名按钮。
- 不设任何"连点直接进正文"。
- 是否给"再次单击＝展开"加快捷，由原型比较误触率后再定。

### 聚合与按需显示规则（推荐）

1. 任一状态，画面上只有焦点、它的子级（完整节点）和孙级（角标或行）。同屏不超过约 60 个。
2. 容器节点永远带计数和已整理比例，让人看得出"还有多少没展开"。
3. **跨册、跨领域的边分三级拆开**：
   - 学科总览里聚合成主线。
   - 聚焦到领域或部分时，聚合成"→ 细胞的代谢与能量 · 3 条关系"这样的端口。
   - 聚焦到单元或概念时，才显示逐条关系和关系词。
4. 一个概念在每个骨架里只有一个主位置，别处是带虚线框的引用。专题和主线的成员全是引用。
5. 兄弟超过 7 个时先显示前 6 个加"显示更多"，先后由数据顺序定。
6. **网络内搜索**查概念名、别名和考点标题。结果里写出所在位置、册名、是否已整理。回车后优先在当前范围内定位，不在则扩大到学科并提示，跳之前的位置进"来路"。顶栏的全站搜索不变。
7. **图和列表等价**：每个状态都有一个列表形态，骨架、选中、展开、信息卡相同，关系逐条写成文字。手机默认用列表，桌面可切换。列表不是降级版，所有功能都要能在列表里完成。

### 延续上一版的约束（不展开）

- 手机用纵向层级清单和底部摘要抽屉，抽屉停在播放器上方。
- 键盘：空格始终归播放器；节点用 Enter；方向键只在焦点位于网络内时归网络。
- 网络页继承主题变量。
- 播放跨期时，不得把人从网络页带到下一期。
- 讲义滚动改写地址时，不得在网络页显示期间生效。
- 聚焦、换范围、换逻辑、进正文各算一步历史。
- 深链里的范围、逻辑、焦点任一项失效时，逐级退到上一层并提示。

## 六、案例

### 案例 1：选必二全书骨架

中心"选必2 生物与环境"，第一圈是 4 个部分和 1 组专题：

| 部分 | 单元（对应的期） | 考点数 |
|---|---|---|
| 种群 | 数量特征与调查（01）、数量变化模型（02）、影响因素与应用（03） | 22 |
| 群落 | 群落的结构（04）、类型与适应（05）、演替（06） | 21 |
| 生态系统 | 结构（07）、能量流动（08–09）、物质循环（10）、信息传递（11）、稳定性（12） | 39 |
| 人与环境 | 人类活动的影响（13）、生物多样性及保护（14）、生态工程（15） | 19 |

合计 101，与本册考点数一致。

部分之间的边要写明类型：
- 种群→群落→生态系统是**真实组成**。依据是第 17 讲图"所有种群集合"，以及 `xb2-07/p1` 原文"生态系统 = 生物群落 + 非生物环境"。
- 生态系统与人与环境之间是**影响**。
- 部分→单元→概念只是**编排归类**，界面上不写"属于"。

**另一种跨章问题视角**是"跨章专题"这一组，成员全是引用，边的类型是**专题收录**：
- "数量为什么变、怎么调"：就是上一版的 33 节点集合，横跨种群、群落、生态系统。
- "物质和能量怎么走"：食物链网（07）、能量流动（08–09）、物质循环（10）、循环原理（`xb2-15/p3`）。
- "系统为什么稳、怎么护"：负反馈（`xb2-12/p1`）、食物网复杂度（`xb2-07/p6`）、稳定性、生物多样性保护（14）。

后两个专题是待你确认的提议。同一个"捕食者与猎物曲线"，从"种群 › 影响因素"进来和从专题进来是同一个节点。位置条不同，信息卡相同。

### 案例 2：从细胞能量到生态系统能量（学科范围）

打开"能量"主线，站点依次是：
1. 合成 ATP 的能量来源 `bx1-16/p4`
2. 光合作用总反应式 `bx1-20/p2`、化能合成作用 `bx1-20/p7`
3. 有氧呼吸的能量与元素去向 `bx1-17/p6`
4. 能量流动的输入 `xb2-08/p1–p2`
5. 碳循环的过程 `xb2-10/p2`

| 边 | 类型 | 依据 |
|---|---|---|
| 光合作用 → 能量流动的输入 | 跨尺度对应：生态层面的"输入"由生产者的光合作用完成 | `xb2-08/p2`："生产者通过光合作用，把太阳能固定在有机物中" |
| 细胞呼吸 → 各营养级的呼吸散失 | 跨尺度对应 | `xb2-08/p2`："在生产者的呼吸作用中以热能的形式散失" |
| 光合、化能合成、呼吸 → 碳循环的进出 | 跨尺度对应 | `xb2-10/p2`："碳进入生物群落，主要靠生产者的光合作用，还有化能合成作用" |
| 总光合与净光合（`bx1-21/p4`）～ 同化量的去向（`xb2-08/p4`） | 类比：都是"总量先扣自身消耗"的收支拆分 | 编辑判断；两者对象不同，不能互换数值；必修1 正文待核 |

"跨尺度对应"不是因果：光合作用不是能量流动的原因，而是其中一步在细胞层面的实现。界面上关系词必须写出来，不能只画一条线。

### 案例 3：同一焦点下切换三种逻辑

焦点是选必2 的单元"能量流动"。

- **知识关系**
  - 子集：概念与输入、流经各营养级、同化量的去向、特点、生态金字塔、计算、实践意义。
  - 关系：食物链网是它的"渠道"（第 18 讲图）；与物质循环互为"动力／载体"（`xb2-10/p6` 原文）；跨册端口通向必修1。
- **大题任务**（示意，未对照真题）："能量流动图解与计算"
  - 步骤：认图找同化量 → 分清摄入、同化、粪便 → 算传递效率 → 极值或按比例分配 → 写实践意义。
  - 每步必须带**适用条件**。例如 `xb2-09/p6` 的句式只适用于"除草、灭虫这类措施有什么意义"的设问。上一版"定措施先写降低 K 值"同理，只适用于从根本上控制有害生物的设问，不是通用模板。
- **推导方法**
  - 所在的组是"收支拆分"和"沿食物链逐级推"。
  - 后者的同组成员有生物富集（`xb2-10/p5`）。卡片要写明不同点：能量逐级递减，富集物浓度逐级升高，方向相反。

**缺内容时怎样显示**：把焦点换成"群落的类型与适应"。任务一栏写"任务 0 · 尚未整理"，下面只列讲义里现成的考法提示并链回考点，例如 `xb2-05/p1`"给出降水量和群落特征，判断群落类型"，再提示"上一级范围'群落'内有 n 个任务"。不为凑数造任务。

## 七、题型关联（延续，只补三点）

- 证据仍分四级：无、讲义线索、个人经验、逐题记录。没有逐题记录时不出现比例和"高频"字样。
- 每条记录必须带年份和地区卷别。不预设任何地区：教辅页边疑似的版别不代表你的考卷。
- 参考图上的星标来历不明，不当作任何依据。
- 在学科和全书范围里，题型信息只在聚焦到概念后出现。上层容器不汇总，避免小样本被加总成结论。

## 八、给 Opus 的交接（文字规格）

### 职责模块

| 模块 | 职责 |
|---|---|
| 概念库 | 稳定 ID、名称、别名、摘要、来源、整理状态；每个概念有一到多个讲义位置，位置带标题快照 |
| 骨架 | 学科→领域→部分→单元；每一期登记到唯一的部分；引用与专题；主线 |
| 关系 | 类型至少区分：编排归类、专题收录、真实组成、因果或影响、先后、实例或依据、对比、类比、跨尺度对应。每条带依据（参考图、站内原文、编辑判断）和确认状态 |
| 任务与方法 | 任务的步骤、适用条件、反例；方法组的成员、共同点、不同点 |
| 题型证据 | 四级结构；首期可以为空 |
| 覆盖补全 | 运行时用站点已有的期和考点数据，为未整理部分生成临时节点；建立"考点→概念"反查 |
| 校验 | 全部期已登记；目标存在；标题快照一致；主位置唯一；无环；输出两种覆盖数字 |
| 布局与呈现 | 发散、展开两种图形态，加一种列表形态；结果确定、可重复 |
| 导航状态 | 范围、逻辑、焦点进地址；选中、展开、滚动为会话态；"回到网络"的语义返回与浏览历史分离 |
| 站点接入 | 三处入口；外壳只做最小改动；讲义页不改 |

### 共存约束

- 无构建、无外部依赖，相对路径，可离线直接打开，直角边框。
- 数据手工维护，独立成文件，不写进生成的站点数据。
- 讲义内容会继续更新，包括已授权的必修1 刷新。网络只把讲义当索引目标，更新后靠标题快照发现并修正映射。
- 临时节点的地址允许失效，失效时经反查落到接管它的概念。

### 成功标准（可逐条比较）

1. **往返**：在六个范围里各取一个已整理概念和一个未整理考点，打开讲义后分别用"回到网络"和浏览器后退返回。范围、逻辑、焦点、选中、展开都与离开时一致。
2. **跨册不迷路**：从选必2 的"能量流动的输入"前往必修1 的光合作用。范围徽标变化有提示，位置条显示新位置，一步能回原处。
3. **语义一致**：同一概念在两个范围、三种逻辑、图与列表中，名称、摘要、讲义位置完全相同；同一条边的关系词处处相同。
4. **多位置**："生物多样性三层次"从必修2 和选必2 两个入口进入，卡片都列出两处讲义位置和全部所在位置。
5. **没有人工关系也可达**：删掉全部人工整理的数据后，732 个考点仍能从所在册的网络到达；原目录、搜索、播放器与现在完全一样。
6. **完整但不拥挤**：任一状态同屏不超过约 60 个节点；没有任何一屏画出某册的全部考点。
7. **覆盖如实**：界面和校验报告分别给出"索引覆盖"与"关系已整理"两个数，不合并。
8. **空状态如实**：没有任务或方法的焦点显示"尚未整理"，不出现凑数内容和任何比例。
9. **列表等价**：只用列表形态和键盘，能完成第 1、2 条。
10. **内容更新**：改一个考点标题或调换顺序后，校验报告指出受影响的概念，网络仍能打开该期。
11. **站点不受损**：讲义文件零改动；离线、子路径、深浅主题、连播都正常。
