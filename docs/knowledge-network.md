# 思维导图：使用、数据维护与校验

思维导图是外壳 `index.html` 里的一种页面，与总索引、本册目录、讲义并列，作为原站的智能索引。方案背景见 [plans/knowledge-network-book-subject-fable.md](plans/knowledge-network-book-subject-fable.md) 与 [plans/knowledge-network-review.md](plans/knowledge-network-review.md)。

- **学科总览、本册总览和领域目录**展示索引结构。点卡片先在原处选中，有讲义或关系图可用时，卡片显示“读讲义”或“看思维导图”。领域卡片上的“展开 ▸”进入该领域目录，卡片右侧的“▸ 数字”在原处展开下一级。总览画布左上角也可展开或收起各分支。
- **知识关系图**按 `KN_DATA.maps` 手工绘制，复刻教材“知识框架”图的方框、分类括线、带关系词的箭头和虚线分组框。单击知识点只选中，画布顶栏显示名称、说明和“读讲义 ›”，点“读讲义 ›”打开对应讲义，顶栏出现“↩ 回到思维导图”。按知识点定位时，对应节点会高亮。

位置只显示在外壳顶栏的路径里（思维导图页内不再重复一行路径）；路径最后一级带 ▾，点一下弹出同级列表切换。

在思维导图页面使用顶栏搜索可查找概念、考点和其他条目，选择结果会定位到对应位置；离开思维导图后搜索恢复全站范围。图支持拖动空白处平移、滚轮缩放和触屏双指缩放。画布下方是工具栏：左边“回正”“全部展开”“全部收起”（没有可展开内容时隐藏），右边“图例”（关系图有图例时）、“覆盖与说明”“全屏”。全屏优先使用浏览器全屏（`requestFullscreen`），不支持时铺满窗口；按 Esc 或再点一次退出，离开思维导图时自动退出。总览上的详情侧栏右上角可关闭，再选择节点可重新打开；关系图页面不显示详情侧栏。

## 地址与入口

| 地址 | 含义 |
|---|---|
| `index.html#/map/bio` | 学科思维导图总览（中心向外） |
| `index.html#/map/xb2` | 选必2 全书思维导图总览 |
| `index.html#/map/xb2/rel/u-xb2-energy` | 选必2 · 知识关系 · 聚焦"能量流动"单元 |
| `index.html#/map/xb2/task` / `…/method` | 大题任务、推导方法两种组织逻辑 |
| `index.html#/map/bio/rel/k-biotic@tg-popnum-why` | 同一条目有多处位置时，`@` 后写所在上级以指定位置 |

入口：总索引与本册目录中的"思维导图"条、侧栏"学科思维导图 / 本册思维导图"、讲义顶栏的"思维导图"按钮（显示当前考点在思维导图中的位置，可选择"在本册思维导图中打开"或"在学科思维导图中打开"）。从思维导图打开讲义后，顶栏出现"↩ 回到思维导图"。

地址记范围、逻辑、焦点。`#/map/xb2/rel/k-pop-density` 这类概念或考点的深链可直接复制和分享，打开时定位到该条目。知识关系目录中原地选中卡片时，地址保持不变。选中、展开和滚动位置按地址保存在 `sessionStorage`。深链中任一部分失效时，会逐级退回并提示。

已整理的考点在骨架中由概念代替，并入单元的期由单元代替：网内搜索的考点、期结果，讲义顶栏的"在本册/学科思维导图中打开"（含期首页、易错速查锚点），以及旧的考点 ID 地址都会落到代替它的概念或单元，并说明对应关系；一个考点拆成多个概念时列出全部，定位到第一个。

"回到思维导图"的返回凭据只属于创建它的标签页：
- 从思维导图"读讲义"进入时生效；在讲义之间连续翻期（讲义内翻页、侧栏、地址、续播跟随）保持；同一标签页刷新讲义保持。
- 回到思维导图、去总索引/本册目录/使用说明，或从这些页面（含思维导图页的侧栏）独立打开讲义时失效，此时只显示"上次思维导图位置"提示。
- 浏览器前进/后退回到那条由思维导图打开的历史项时重新生效。
- 新标签页不继承别的标签页的凭据。
限制：在讲义页内直接改地址栏打开另一篇讲义，与连续翻期无法区分，按连续阅读处理。

## 两种覆盖

- **索引覆盖**：能从所在册思维导图到达的现有考点位置数 / 当前考点总数。未整理的部分在运行时按"期 → 考点"自动列出（样式较素、标"未整理"），所以即使删掉全部手工数据，所有考点仍可达。
- **关系已整理**：分别统计人工整理的概念数和关系数；关系再按依据状态分开（原文可查 / 编辑判断待确认 / 仅据标题）。没有定义"全部关系"的总量，所以不给完成百分比。

考点数不等于概念数：一个概念可以挂多个讲义位置（如"生物多样性的三个层次"挂在必修2与选必2），一个考点也可以拆成多个概念（如"防治与渔业"拆成防治、渔业两个）。

界面的“覆盖与说明”展示覆盖统计与关系类型。数据校验仍在内部执行，发现问题时写入浏览器控制台；自动化测试可通过 `window.__kn.report()` 检查完整报告。

## 知识关系图（`maps`）

每张图是一个对象，坐标单位 px（节点文字 14px），画布大小由内容自动决定。还原一张手绘图时，按图上位置填写坐标即可，节点宽高按文字自动计算。

| 字段 | 说明 |
|---|---|
| `id`、`name`、`source` | 图的标识、名称、来源说明 |
| `anchors` | 哪些领域、部分进入后显示本图；从当前位置沿上级找最近的锚点。一个锚点只属于一张图 |
| `nodes` | `{ id, t, x 或 lx, y, go, s }`：`t` 文字（`\n` 换行）；`x`/`y` 为中心坐标，`lx` 为左缘（用于一列左对齐）；`go` 为讲义落点 `'期/锚点'` 或 `'期'`，选中后顶栏的“读讲义 ›”打开它；`s: 'main'` 为加粗主干 |
| `groups` | `{ id, of, style }`：`dash` 虚线框；`join` 在成员一侧（`side: 'l'/'r'`）加括线并合成一个端点；`bracket` 在成员一侧画带端钩的大方括号，括住整列，中点作端点（如“延伸 → 蛋白质工程”）；`none` 只合成端点 |
| `edges` 连线 | `{ from, to, arrow, label, lp, lv, via, fs, ts, straight, note }`：`arrow` 为 `end`/`start`/`both`；`label` 关系词，`lp` 标签中心，`lv` 竖排；`via` 折点；`fs`/`ts` 指定出入边（`l`/`r`/`t`/`b`）；`straight` 画斜直线；`note` 悬停说明 |
| `edges` 分类括线 | `{ fork, to, dir, at, label, arrow }`：从上级 `fork` 向 `dir` 方向引出主干，在 `at` 处分到各下级；`label` 写在主干上 |
| `texts` | `{ t, x, y, lv }` 独立文字，如括线分支上的“最基本特征” |

连线端点可以是节点或分组。正交连线会按端点和折点自动补拐角；后画的线在交叉处断开先画的线。加载时校验节点 ID、端点、讲义落点和锚点，问题写入浏览器控制台；`window.__kn.mapGeom()` 返回当前图的节点框和标签框，可用于检查重叠。

### 扩展画法（`m-resp` 细胞呼吸起使用）

教材框架图只列"有哪些"，不能看出知识点之间怎样联系。扩展画法借鉴概念图（Novak 概念图）的做法：每条线写关系词，可读成"知识点 → 关系词 → 知识点"。为了先看清结构，图默认只显示主干，细节按模块收起，点击逐步展开；跨区联系不常驻画出，点选时才用临时连线标出。方案见 [plans/relation-map-progressive-disclosure.md](plans/relation-map-progressive-disclosure.md)。

| 字段 | 说明 |
|---|---|
| 节点 `s` | 新增 `sub` 物质（浅绿底）、`detail` 要点细节（13px，左对齐，可多行）、`warn` 易错（红色虚线框）、`eq` 反应式（灰底无框）、`ext` 其他模块的知识点（金色虚线框）、`mod` 模块入口（加粗、粗边框） |
| 节点 `d` | 第二行小字，如阶段的场所（"细胞质基质"） |
| 节点 `tip` | 一句说明，选中后显示在顶栏 |
| 节点 `open: '模块名'` | 该节点是模块开关，右侧显示 ＋ / － |
| `in: '模块名'` 或数组 | 写在节点、连线、分组或独立文字上：只在所列模块之一展开时显示。连线还要求两端都可见；分类括线的主干要求上级可见且至少一个下级可见；区域要求至少一个成员可见。不写 `in` 的属于主干，始终显示 |
| 图 `art` | **示意图底图**，画在主干下面，表示场所：`{ id, shape: 'rect', x, y, w, h, t, lp }` 一块场所（如细胞质基质，虚线框）；`{ id, shape: 'mito', cx, cy, rx, ry, t, lp, matrix, mp, inner, ip, cristae: [{ x, side: 't'/'b', len }] }` 线粒体，画外膜、基质、内膜和向内折叠的嵴，拆成 `id-outer`、`id-matrix`、`id-inner` 三个部分；`t`/`matrix`/`inner` 是标签，`lp`/`mp`/`ip` 是标签左上角坐标 |
| 节点 `at` | 知识点所在的场所（`art` 的 id 或其部分，如 `'cyto'`、`'mito-matrix'`、`'mito-inner'`）。选中它，或选中的知识点的关联里有它时，对应场所加深并变绿 |
| 节点 `rel` | **知识点的关联**（优先于 `marks`），每条一种：`{ scope: [id…], t }` 范围——用虚线框把一组知识点框起来，框外写说明（如"有氧呼吸 = 第一阶段 + 第二阶段 + 第三阶段"）；`{ trace: [id…], t }` 路线——按先后经过各知识点画一条荧光笔式宽带（如物质变化、元素去向）；`{ to: id, tag, why }` 单条关联——从选中项画弧线到对方，对方挂编号，关联面板按编号写出 `tag`（特点、去向、计算、判断、比较、检测、实验、应用、影响、易错）和原因 `why`。选中时只突出关联涉及的知识点和它们之间本来就画着的线；涉及的知识点在收起的模块里时先展开 |
| 节点 `marks: [节点 id…]` | 旧写法，没有 `rel` 时使用：选中时标出的相关知识点，从选中项向它们画临时连线（红虚线）；对象在收起的模块里时先展开该模块。用于易错点、实验检测、应用等跨区联系 |
| 分组 `style: 'zone'` | 浅色底框加区域名，表示同一场所或同一主题；`title` 区域名，`talign: 'r'` 区域名放右上角，`go` 让区域名可点开讲义，`pad`/`top` 调边距。连到区域的线（如模块入口 → 模块内容）不把区域成员算作端点 |
| 连线 `k` | 连线语义：`flow` 物质转化（蓝，箭头指向产物）、`link` 相关内容（红虚线，`marks` 的临时连线也用它）、`apply` 原理→应用（青）、`contrast` 对比（紫点线）、`ext` 联系其他模块（金虚线）；不写为结构线 |
| 图 `legend` | 默认自动显示图例（只列本图用到的连线和节点样式），折叠为"图例"两个字；`legend: false` 关闭 |

关联的画法：范围框表达"由哪些部分组成"，路线表达"物质或元素按什么先后变化"，带编号的关联线加面板里的原因表达"为什么相关"。关联线也是直角折线（画面里只有线粒体等示意图是曲线），用颜色、箭头和线上的标签与主干区分：从知识点上下边引出走横向通道，或左右边引出走竖向通道；通道由近到远逐级试，取标签不压住知识点、场所标签、编号和其他标签，且线穿过的知识点最少、与已有关联线不重叠的一条，所以知识点挤在一起时关联线会绕远，空出地方写标签。

选中有 `rel` 的知识点时，画布右侧（窄屏在底部）出现关联面板，标题可点击折叠（窄屏默认折叠）。点条目平移到那个知识点并闪一下，悬停条目加粗对应的线和编号。视口把选中项、全部关联知识点、关联线和线上标签正好放满可用区域（缩放 0.2–1.4）。可用区域每次实测：画布减去顶栏和关联面板；进出全屏、窗口大小变化、面板折叠后都会重新测量并适配（手动平移缩放过则保持手动视口，进出全屏时重新适配）。

交互（所有关系图通用）：悬停只改变边框颜色。单击知识点选中它（有 `rel` 时按关联突出，见上）：与它直接相连的线、关系词和知识点保持原色，其余变淡（分类括线的主干只把上级算作邻居；选中展开着的开关时，它模块里的内容都算相关），`marks` 标出的知识点加框并有临时连线。画布顶栏显示名称、`tip`、"读讲义 ›"（带期号与考点名）、开关的"展开细节 / 收起细节"和 ×；"全部展开 / 全部收起"在底部工具栏。点空白处（非拖动）、按 Esc 或点 × 取消选中。

开关：第一次点击展开它的细节并选中；已选中时再点收起；展开着但未选中时只选中。展开不重排，细节出现在预留位置；视口只在需要时平移到看得见（放不下时缩小到可读下限，并保证被点的知识点可见）。布局时要为每个模块预留位置，保证"全部展开"后互不重叠。展开的模块和选中项随地址存入 `sessionStorage`，从讲义"回到思维导图"时恢复。

图例由底部工具栏的"图例"按钮打开，显示在画布右下角；其中的连线种类可点击，暂时隐藏或显示该种连线。

其他画法：竖排文字用逐字 `\n` 换行；`s: 'bare'` 无框文字（如“DNA”“血浆”），`s: 'note'` 虚线注释框；连线 `{ loop: 节点, side, r, dash }` 画绕节点一侧的循环箭头（如 DNA 的复制）；`straight: true` 加 `via` 画经过折点的斜折线（如生物体 → 精子、卵细胞的菱形）。

## 维护数据

在 `knowledge-network-data.js` 中按注释格式添加。要点：

1. **ID** 用小写字母、数字、连字符的语义短名，不要写成期号格式（如 `xb2-03`）。概念改名只改 `name`，ID 不动。
2. **讲义位置**写成 `"期/锚点"` 并带标题快照 `t`；第一个位置决定概念在骨架中的主位置，其余位置显示为虚线框"引用"。
3. **关系**必须写 `type`、`label`（关系词，处处显示同一句）、`status` 与 `basis`。`status: 'site'` 时至少有一条 `kind: 'site'` 的引文，且引文必须能在对应考点段落中逐字查到。类比、对比等写明 `condition`（对象、适用条件、差异）。
4. **任务步骤**写 `when`（适用条件）、必要时写 `not`（不适用的情况），不要把示意步骤写成通用模板。
5. **题型记录**每条写年份、地区卷别、题号、题型、涉及概念；没有记录时保持空数组。

讲义更新后（包括必修1 刷新），先运行校验：标题快照对不上、考点序号越界或期不存在都会报出受影响的条目。期存在而考点失效时思维导图回退到该期开头；期不存在时回退到本册目录；同期内唯一同名的考点只作为修复候选显示，不会自动改写映射。
