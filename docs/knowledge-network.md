# 知识网络：使用、数据维护与校验

知识网络是外壳 `index.html` 里的一种页面，与总索引、本册目录、讲义并列，作为原站的智能索引。方案背景见 [plans/knowledge-network-book-subject-fable.md](plans/knowledge-network-book-subject-fable.md) 与 [plans/knowledge-network-review.md](plans/knowledge-network-review.md)。

在网络页面使用顶栏搜索可查找网络中的概念、考点和其他条目；选择结果会定位到网络中的对应节点，离开网络后搜索恢复原有的全站范围。总览图支持拖动空白处平移、滚轮缩放和触屏双指缩放，左上角“回正”恢复居中。底部主线按钮只控制相应连线的显示，可同时叠加；点击图中主线标签查看详情。能量主线为蓝色，其他主线沿用各自颜色。

详情侧栏右上角的关闭按钮会隐藏侧栏；再选择节点或主线标签可重新打开。顶部有多个可选详情时可用下拉菜单切换，只有一个选项时显示其名称。手机上详情显示为底部抽屉。

## 地址与入口

| 地址 | 含义 |
|---|---|
| `index.html#/map/bio` | 学科网络总览（中心向外） |
| `index.html#/map/xb2` | 选必2 全书网络总览 |
| `index.html#/map/xb2/rel/u-xb2-energy` | 选必2 · 知识关系 · 聚焦"能量流动"单元 |
| `index.html#/map/xb2/task` / `…/method` | 大题任务、推导方法两种组织逻辑 |
| `index.html#/map/bio/rel/k-biotic@tg-popnum-why` | 同一条目有多处位置时，`@` 后写所在上级以指定位置 |

入口：总索引与本册目录中的"知识网络"条、侧栏"学科知识网络 / 本册知识网络"、讲义顶栏的"网络"按钮（显示当前考点在网络中的位置，可"在本册/学科网络中打开"）。从网络打开讲义后，顶栏出现"↩ 回到网络"。

地址记范围、逻辑、焦点。焦点是没有下级的叶子（概念或考点）时，地址就是叶子本身，如 `#/map/xb2/rel/k-pop-density`：打开时显示它的上级并选中它，可直接复制、分享或在新标签页打开；在同一焦点下改选别的叶子或取消选中时，地址用 `replaceState` 同步，不新增历史。展开、滚动位置保存在 `sessionStorage`（按地址），地址与会话记录冲突时以地址为准。深链中任一部分失效时逐级退回并提示。

已整理的考点在骨架中由概念代替，并入单元的期由单元代替：网内搜索的考点、期结果，讲义顶栏的"在本册/学科网络中打开"（含期首页、易错速查锚点），以及旧的考点 ID 地址都会落到代替它的概念或单元，并说明对应关系；一个考点拆成多个概念时列出全部，定位到第一个。

"回到网络"的返回凭据只属于创建它的标签页：
- 从网络"读讲义"进入时生效；在讲义之间连续翻期（讲义内翻页、侧栏、地址、续播跟随）保持；同一标签页刷新讲义保持。
- 回到网络、去总索引/本册目录/使用说明，或从这些页面（含网络页的侧栏）独立打开讲义时失效，此时只显示"上次网络位置"提示。
- 浏览器前进/后退回到那条由网络打开的历史项时重新生效。
- 新标签页不继承别的标签页的凭据。
限制：在讲义页内直接改地址栏打开另一篇讲义，与连续翻期无法区分，按连续阅读处理。

## 文件

| 文件 | 说明 |
|---|---|
| `assets/js/knowledge-network-data.js` | **手工维护**的数据（`window.KN_DATA`），不由 build.py 生成 |
| `assets/js/knowledge-network.js` | 模型、兜底补全、校验、布局、渲染、导航状态 |
| `assets/css/knowledge-network.css` | 样式，沿用站点颜色变量并定义能量主线蓝色，全部直角 |
| `assets/js/app.js` | 外壳路由增加 `#/map/…` 分支；网络页显示时忽略隐藏讲义的滚动消息、不跟随跨期翻页；滚动改写地址时保留 `history.state` |
| `index.html` | 只增加 1 个样式表和 2 个脚本引用；入口在运行时插入 |

生成的 `site-data.js`、`search-data.js`、`playlist.js` 与讲义页面均未改动，网络只读取它们。

## 两种覆盖

- **索引覆盖**：能从所在册网络到达的现有考点位置数 / 当前考点总数。未整理的部分在运行时按"期 → 考点"自动列出（样式较素、标"未整理"），所以即使删掉全部手工数据，所有考点仍可达。
- **关系已整理**：分别统计人工整理的概念数和关系数；关系再按依据状态分开（原文可查 / 编辑判断待确认 / 仅据标题）。没有定义"全部关系"的总量，所以不给完成百分比。

考点数不等于概念数：一个概念可以挂多个讲义位置（如"生物多样性的三个层次"挂在必修2与选必2），一个考点也可以拆成多个概念（如"防治与渔业"拆成防治、渔业两个）。

界面的“覆盖与说明”展示覆盖统计与关系类型。数据校验仍在内部执行，发现问题时写入浏览器控制台；自动化测试可通过 `window.__kn.report()` 检查完整报告。

## 当前整理范围（2026-11-15）

- 8 个领域（顺序是编辑安排，不是严格尺度序列）、32 个部分，104 期全部登记到唯一部分。
- 选必2 整理到单元（14 个）；其余四册单元未整理，以"期"顶替。
- 63 个概念、39 条关系：34 条依据站内讲义原文（引文可逐字查到），5 条为编辑判断待确认。"原文可查"只说明讲义这样写，不代表另经专家审定。
- 跨章专题 3 个（"种群数量"为编辑整理；另 2 个为提议待确认）；跨册主线 4 条（能量、调节与反馈、进化与适应、技术回扣原理）。
- 大题任务 2 个、推导方法组 4 个，均为示意或编辑判断，未对照真题。
- 题型逐题记录 0 条：界面不显示任何比例或"高频"字样；"讲义线索"取自旁白中的考法提示，只说明讲义讲到了怎么考。

## 维护数据

在 `knowledge-network-data.js` 中按注释格式添加。要点：

1. **ID** 用小写字母、数字、连字符的语义短名，不要写成期号格式（如 `xb2-03`）。概念改名只改 `name`，ID 不动。
2. **讲义位置**写成 `"期/锚点"` 并带标题快照 `t`；第一个位置决定概念在骨架中的主位置，其余位置显示为虚线框"引用"。
3. **关系**必须写 `type`、`label`（关系词，处处显示同一句）、`status` 与 `basis`。`status: 'site'` 时至少有一条 `kind: 'site'` 的引文，且引文必须能在对应考点段落中逐字查到。类比、对比等写明 `condition`（对象、适用条件、差异）。
4. **任务步骤**写 `when`（适用条件）、必要时写 `not`（不适用的情况），不要把示意步骤写成通用模板。
5. **题型记录**每条写年份、地区卷别、题号、题型、涉及概念；没有记录时保持空数组。

讲义更新后（包括必修1 刷新），先运行校验：标题快照对不上、考点序号越界或期不存在都会报出受影响的条目。期存在而考点失效时网络回退到该期开头；期不存在时回退到本册目录；同期内唯一同名的考点只作为修复候选显示，不会自动改写映射。

## 校验与测试

测试脚本不随站点发布（站点仓库只含发布内容）。本次实现使用的检查：

- 数据校验（Node）：每期登记唯一、ID 不冲突、讲义位置与标题快照、所有 `kind: 'site'` 引文逐字可查、关系端点与类型、专题/主线/任务/方法的成员存在。
- 浏览器交互（Playwright + Chromium，`file://` 直接打开）：覆盖 732/732、往返恢复（"回到网络"与浏览器后退）、跨册前往与来路、同一概念在两种范围/三种逻辑/图与列表中信息卡一致、多位置、同屏节点数、空状态、键盘与列表、快速连点、确定性、深链回退、跨期播放、原站搜索与深链、主题与直角、手机 390px、删掉手工数据后的可达性、改标题与调序后的校验报告。
