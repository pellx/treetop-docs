# 播放栏阅读器与歌词显示要求

日期：2026-11-17

本文记录底部播放栏、整期进度条、快速跳转与顶部/底部歌词行的界面要求，供后续修改和验收使用。相关实现集中在 `assets/js/app.js` 的 `bindPlayerUI`、`assets/css/site.css`（播放器与 `.pl-topline` 部分）。

## 一、底栏信息行

- 上行显示：小节（期）名、本节句子序号 `x/xx`、知识点名、本知识点句子序号 `x/xx`。
- 序号一律写作 `x/xx`，不加括号、不加“第…句”等中文。
- 四个部分都可以点击，点击后在该部分附近弹出同级列表：
  - 小节名 → 本册所有小节（期），显示期号与标题；
  - 本节句序 → 本节所有句子，显示 `x/xx` 与句子原文；
  - 知识点名 → 本期所有知识点（导读、考点 1…n、易错速查）；
  - 本知识点句序 → 本知识点内所有句子。
- 列表当前项高亮，选中任意项直接跳到对应句子并开始播放；跳转跨期时先切换讲义页面。
- 标题整体靠左，不水平居中；但信息块在播放栏内竖直居中。
- 两个句序数字固定靠最右边缘，二者之间不再显示“·”分隔。
- 窄屏（放不下完整名称）时，小节名与知识点名必须同时出现：按完整文字宽度比例分配剩余空间，各自用两个点 `..` 收尾（不用省略号 `…`），并缩小两个名称之间、名称与数字之间的间距。
- 播放过程中同一知识点内只更新计数，不重建标题，避免已打开的跳转菜单被顶掉；换期或换知识点时才重建并关闭菜单。

## 二、整期进度条

- 进度条表示整个小节（一期）所有句子的总进度，而不是当前一句的进度。
- 按知识点分段，段与段之间留 2px 空隙；每句开始处显示 1px 刻度，刻度用亮色（`--fg-dim`），不用暗色。
- 只有鼠标所在（或拖动经过）的那一段加宽，其余段保持细条；桌面悬停、手机拖动都生效。
- 点击任意位置定位到该位置所在句子的开头，不在句子内部截取；拖动同样按句子开头对齐。
- 悬停/拖动时显示小预览卡片：知识点名、`x/xx`、当前时间 / 总时长。
- 预览卡片靠近左右边缘时向内挤，不能被视口裁掉；文字过长时卡片也不越界。
- 移动端进度条本体加粗到 6px，触摸热区 22px，便于手指点按。
- 播放时按整期进度连续增长；暂停、切句、拖动预览都要同步。

## 三、朗读歌词行

- 正在朗读的整句从播放栏移到文档之上，像音乐软件歌词一样浮动显示；播放栏不再重复这句话。
- 位置：
  - 桌面端（宽度 > 899px）：贴在播放栏上方约 10px，横向居中于右侧正文区域（左侧让开侧栏宽度 `--side-w`）。
  - 手机端（≤ 899px）：贴在顶栏下方，横向铺满全宽并居中。
- 样式：20px、粗体、衬线字体（`Noto Serif SC` / `Songti SC` / `SimSun` 等），黄色文字（深色主题 `#ffcc33`，浅色主题 `#a06a00`），无背景色，1.4px 深色描边（`#1b1200`）保证在正文上也可辨认，最多两行，超出省略。
- 关闭：
  - 桌面端鼠标悬停到歌词文字上，文字块的右上角出现关闭按钮；
  - 手机端长按歌词约 450ms，在文字块右上角唤出关闭按钮；
  - 关闭按钮属于文字块本身，不是整条视口的右边缘；短句时跟随文字块收拢。
- 关闭后，在原位置（桌面右下、手机右上）显示一个字幕样式的小按钮，点击恢复歌词。
- 歌词区域不响应文本选择；“本期播放完毕/加载失败”等状态仍显示在播放栏第二行。

## 四、播放控制

- 离开讲义页（底部播放栏消失）时立即暂停音频，并清除已排队的“下一句”，避免移动端在无可操作控件时继续播放。
- 上一句/下一句、空格播放暂停、左右方向键切句等原有快捷键保持不变。

## 五、内容页配套调整

- BX1-01 考点 1 的时间线卡片一行三个；700px 以下两列，480px 以下单列；卡片内边距、编号和字号收紧。
- BX1-01 考点 2 列表前的编号方块宽度为 22px，不再被文字挤成细条。

## 六、验收清单

- [ ] 播放任意讲义，底栏标题左侧靠左、竖直居中，两个计数靠最右且中间无分隔符。
- [ ] 四个可点击部分分别弹出正确的同级列表，选中后跳转并播放。
- [ ] 360px 宽时两个名称都出现且以 `..` 结尾，间距明显收窄。
- [ ] 进度条覆盖整期，按知识点分段、句间有亮色刻度；悬停只加粗对应段。
- [ ] 点击进度条任意位置，从该句开头播放；左右边缘的预览卡片完整可见。
- [ ] 桌面歌词在播放栏上方且按正文区域居中；手机歌词在顶栏下方。
- [ ] 歌词为黄色衬线字、无底色、深色描边；桌面悬停/手机长按在文字右上角出现关闭按钮。
- [ ] 关闭后出现字幕小按钮，点击恢复歌词。
- [ ] 离开讲义时声音停止，返回后需手动继续。
