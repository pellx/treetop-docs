使用方法

「树梢文档」是纯静态网页，可直接双击 HTML 文件打开，也可用任意本地静态服务器访问；不需要联网。

两种打开方式01

  • 连播模式（推荐）：打开根目录的 index.html。左侧目录、顶部搜索、底部播放器都在外壳里，正文在中间区域切换；翻页、搜索跳转不会打断语音，一期播完自动进入本册下一期，播到本册最后一期停止，不会跨册。
  • 五册总索引与本册目录：根目录 index.html 打开时是五册总索引；点一册进入该册的本册目录（如 index.html#/bx2），左侧目录、搜索和播放清单随之切换到这一册。
  • 单页模式：直接双击 biology/required-1/bx1-01.html 等页面。页面自带目录和播放器，只播放本期内容。页头的“在连播模式中打开”可切换到连播模式。
  • 深链：index.html#/bx1-01/p3 打开 BX1-01 的第 3 个考点；index.html#/bx1-01/co3 定位到该期的某一句旁白；index.html#/bx1 打开必修1 的本册目录，index.html#/bx1-ch2 定位到其中第 2 章。
  • 左上角品牌旁的小按钮可在日间 / 夜间模式间切换，选择会保存在本机。

目录导航02

左侧目录分四层：册 → 章 → 小节（一期视频）→ 考点。点击章名可折叠或展开；当前页面与正在阅读（或正在播放）的考点会高亮。每页底部有“上一节 / 下一节 / 回到总索引”，上一节 / 下一节只在本册内。连播模式中左侧只显示当前一册：“总索引”回到五册列表，“本册目录”回到本册的章节表。

搜索03

按 Ctrl + K（Mac 为 ⌘ + K）或点击顶部搜索框，输入即过滤。搜索范围包括期标题、考点名、章名、讲义正文和视频原话；多个关键词用空格分开。在某一册中只搜索本册；在五册总索引和本页搜索全部五册。用 ↑ ↓ 选择、回车跳转、Esc 关闭。

语音播放04

  • 每个段落左侧的 ▶ 从该段对应的第一句开始播放；考点标题旁的 ▶ 从该考点第一句开始；“视频原话”折叠块里每句都可单独播放。
  • 播放顺序与视频一致：导读 → 各考点 → 易错速查。正在播放的段落会高亮并自动滚动到可见位置，左侧目录同步高亮所在考点。
  • 底部播放器：上一句 / 播放暂停 / 下一句，语速 0.5×–3×（点一下展开选择），并显示当前“期 · 考点”与句子进度。

键盘快捷键05

按键功能
空格播放 / 暂停当前朗读（未开始时从本期或第一期开头播放）
小键盘 4 / 小键盘 6上一句 / 下一句。连播模式中会跨期继续，单页模式只在本期内切换
← / →上一句 / 下一句（笔记本没有小键盘时的备选）
Ctrl + K（Mac：⌘ + K）聚焦搜索框
↑ ↓ Enter Esc在搜索结果中选择、跳转、关闭
  • 光标在搜索框等输入框中时，上述朗读快捷键不生效，不会干扰输入。
  • 空格被用作播放 / 暂停后不再滚动页面；用滚轮、PageUp / PageDown 或方向键 ↑ ↓ 翻页。
  • 没有在朗读时，← / → 与小键盘 4 / 6 不会自动开始播放，以免误触；按空格或点 ▶ 开始。
  • 快捷键同样适用于单页模式（直接打开的 bx1-XX.html），只在本期内切换。

手机与平板06

屏幕宽度小于 900px 时，左侧目录自动收起：点左上角 ☰ 打开，点遮罩或选择条目后关闭。播放器固定在底部。手机浏览器通常不能直接打开本地文件，可在电脑上启动局域网静态服务器后用手机访问。

讲义结构07

每期页面：期头（编号、小节、考点数、视频时长、封面）→ 本期导读 → 各考点（讲义正文、高考怎么考、易错点、解题方法、可折叠的视频原话）→ 易错速查判断题（点击查看对错与解析）→ 图片来源。尚未整理讲义的期在页首标有“待扩写”，正文暂以视频旁白原文呈现。
