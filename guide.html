使用方法

「树梢文档」是纯静态网页，可直接双击 HTML 文件打开，也可用任意本地静态服务器或在线地址访问；本地使用不需要联网。

打开方式与页面层级01

  • 连播模式（推荐）：打开根目录的 index.html。左侧目录、顶部搜索、底部播放器都在外壳里，正文在中间区域切换；翻页、搜索跳转不会打断语音，一期播完自动进入本册下一期，播到本册最后一期停止，不会跨册。
  • 总索引 → 本册目录 → 讲义：index.html 打开时是五册总索引，列出各册的章数、期数、考点数和章节目录；点书名进入该册的本册目录（如 index.html#/bx2），左侧目录、搜索和播放清单随之切换到这一册；再点某一期进入讲义。本册目录中每期旁的 ▶ 可直接从该期开始连播。
  • 思维导图：与总索引、本册目录、讲义并列的另一种页面，按知识关系查找考点，见第 05 节。
  • 单页模式：直接双击 biology/required-1/bx1-01.html 等页面。页面自带本册目录和播放器，只播放本期内容。标题旁的“在连播模式中打开”可切换到连播模式。
  • 深链：index.html#/bx1 打开必修1 的本册目录，index.html#/bx1-ch2 定位到其中第 2 章；index.html#/bx1-01/p3 打开 BX1-01 的第 3 个考点；index.html#/bx1-01/co3 定位到该期的某一句旁白；index.html#/map/bio、index.html#/map/xb2 打开学科或某一册的思维导图。阅读和浏览思维导图时地址会随当前位置更新，可直接复制分享。
  • 日间 / 夜间模式：左侧目录顶部品牌旁的小按钮切换，选择会保存在本机。

目录与顶栏路径02

  • 左侧目录分四层：册 → 章 → 小节（一期）→ 考点。连播模式中只显示当前一册：“总索引”回到五册列表，“本册目录”回到本册的章节表，“本册思维导图”（总索引时为“学科思维导图”）打开思维导图。当前页面与正在阅读（或正在播放）的考点会高亮。
  • 展开与收起：点击章名折叠或展开该章；册名下的“全部展开 / 全部收起”作用于整本书；章名和小节旁的小按钮分别展开或收起本章、本节的考点。
  • 调整宽度：拖动目录右边缘改变宽度，双击恢复默认；键盘聚焦到边缘后可用 ← → 微调。宽度保存在本机。
  • 顶栏路径：顶栏显示可点击的路径，最左侧的图标回到总索引，其后依次是所属教材、章和当前期（思维导图页显示范围与当前焦点）。空间不足时中间部分收成省略号，点击省略号返回上一级目录。
  • 翻页：每期讲义底部有“上一节 / 下一节 / 回到总索引”，上一节 / 下一节只在本册内。

搜索03

  • 按 Ctrl + K（Mac 为 ⌘ + K）或点击顶部搜索框，输入即过滤。搜索范围包括期标题、考点名、章名、讲义正文和视频原话；多个关键词用空格分开。用 ↑ ↓ 选择、回车跳转、Esc 关闭。
  • 范围：在某一册中只搜索本册；在五册总索引和本页搜索全部五册。结果较多时只显示前 40 条，可再加关键词缩小范围。
  • 在思维导图页：顶栏搜索改为查找思维导图中的概念、考点和其他条目，选择结果会定位到对应节点；此时也可按 / 聚焦搜索框。离开思维导图后恢复原有搜索范围。
  • 顶栏较窄时：搜索框自动收成一个图标按钮，点击展开并聚焦，再点一次收起；快捷键同样会展开它。

语音播放04

  • 标题旁的“播放本期”从导读开始播放；每个段落、表格或图示旁的 ▶ 从对应的那一句开始；考点标题旁的 ▶ 从该考点第一句开始；“视频原话”折叠块里每句都可单独播放。
  • 播放顺序与视频一致：导读 → 各考点 → 易错速查。正在播放的内容会高亮并自动滚动到可见位置，左侧目录同步高亮所在考点。
  • 底部播放器：上一句 / 播放暂停 / 下一句，语速 0.5×–3×（点一下展开选择），并显示当前“期 · 考点”与句子进度。
  • 连播模式中，播放器只在讲义页显示；总索引、本册目录、思维导图和本页不显示播放器，但切换到这些页面不会停止正在播放的语音，回到讲义后播放器恢复。
  • 播放清单只含一册：浏览其他册不影响正在播放的册，在另一册点 ▶ 开始播放时才切换。

思维导图05

  • 两种范围：学科思维导图（index.html#/map/bio）把 8 个知识领域从中心向外展开，可叠加 4 条跨册主线；全书思维导图（#/map/bx1 … #/map/xb3）列出本册各部分。用顶栏的两个菜单切换逻辑与范围。
  • 入口：总索引和本册目录中的思维导图入口、左侧目录的“学科思维导图 / 本册思维导图”、讲义顶栏的“思维导图”按钮（显示当前考点在思维导图中的位置，可选择在本册或学科思维导图中打开）。
  • 组织逻辑与形态：顶栏左侧“组织逻辑”可选知识关系、大题任务、推导方法，统一用关系图呈现；需要成列的内容在选中后的信息卡里查看。
  • 节点操作：单击节点只选中并显示信息卡；“展开 ▸”查看下一层；“读讲义 ›”进入对应考点。从思维导图进入讲义后，顶栏出现“↩ 回到思维导图”，点击回到刚才的范围、逻辑、焦点和展开状态。
  • 知识关系图：单击知识点只选中，与它相关的内容保持原色、其余变淡，画面自动缩放到正好装下这些内容；画布顶栏显示说明和“读讲义 ›”， 右侧（手机在底部）的关联面板写出每条关联的原因。带 ＋ 的知识点同时展开细节。点空白处或按 Esc 取消选中。
  • 底部工具栏：左边“回正”“全部展开”“全部收起”，右边“图例”“覆盖与说明”“全屏”。全屏时只显示思维导图，再点一次或按 Esc 退出。
  • 平移与缩放：拖动空白处平移，滚轮或触屏双指缩放，“回正”重新适配画面。
  • 主线：底部主线按钮切换相应连线，可同时叠加。桌面端点击按钮同时打开该主线的详情；手机上按钮只切换连线，点图中的主线标签查看详情。
  • 详情侧栏：右上角的关闭按钮隐藏侧栏，再选节点或主线标签重新打开；有多个可选详情时用顶部下拉菜单切换。手机上详情显示为右侧面板。
  • 键盘：Tab 选到节点后按 Enter 选中，方向键在思维导图内移动，空格仍控制播放器。
  • 覆盖与说明：所有考点都能从所在册的思维导图到达；尚未整理关系的部分按讲义顺序列出并标注“未整理”。“覆盖与说明”面板列出覆盖统计和关系类型。

键盘快捷键06

按键 功能
空格 播放 / 暂停当前朗读（未开始时从本期或本册第一期开头播放）
小键盘 4 / 小键盘 6 上一句 / 下一句。连播模式中会在本册内跨期继续，单页模式只在本期内切换
← / → 上一句 / 下一句（笔记本没有小键盘时的备选）
Ctrl + K（Mac：⌘ + K） 聚焦搜索框（搜索框收起时先展开）
/ 在思维导图页聚焦搜索框
↑ ↓ Enter Esc 在搜索结果中选择、跳转、关闭
  • 光标在搜索框等输入框中时，上述朗读快捷键不生效，不会干扰输入。
  • 空格被用作播放 / 暂停后不再滚动页面；用滚轮、PageUp / PageDown 或方向键 ↑ ↓ 翻页。
  • 没有在朗读时，← / → 与小键盘 4 / 6 不会自动开始播放，以免误触；按空格或点 ▶ 开始。
  • 快捷键同样适用于单页模式（直接打开的 bx1-XX.html），只在本期内切换。

手机与平板07

屏幕宽度小于 900px 时，左侧目录自动收起：点左上角 ☰ 打开，点遮罩或选择条目后关闭。讲义页的播放器固定在底部；顶栏搜索收成图标按钮；思维导图默认以列表显示，详情为右侧面板。

讲义结构08

每期页面：标题与“播放本期” → 本期考点（带各考点时长的页内目录）→ 本期导读 → 各考点 → 易错速查 → 图片来源 → 翻页。

  • 考点正文由视频画面转换而来：表格、分类树、流程和图示，每一块都绑定对应旁白。
  • 提示框：按原视频内容标为“易错”“解题方法”“考法”等，不是每个考点都有全部类别。
  • 视频原话：每个考点末尾的折叠块，逐句列出旁白原文和时长，可单句播放。
  • 易错速查：判断题，先自己判断，再点“对 / 错”查看结果与解析。
