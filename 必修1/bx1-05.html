糖类的元素与功能01#

糖类一般由C、H、O三种元素构成。

糖类是细胞的重要能源物质，其中葡萄糖是细胞生命活动所需要的主要能源物质，常被称为“生命的燃料”。糖类还能构成细胞结构，比如纤维素是植物细胞壁的主要成分。

高考怎么考
判断“糖类都是能源物质”——错误，纤维素、核糖、脱氧核糖等不供能。
易错点
糖类不都是能源物质——纤维素、核糖、脱氧核糖都不为细胞供能；几丁质还含有N。
解题方法
糖类功能分两类：供能（葡萄糖等）和构成结构（纤维素、核糖、脱氧核糖等），遇到“都是能源物质”的说法先想反例。
视频原话4 句
  1. 考点一，糖类的元素组成与功能。糖类一般由C、H、O三种元素构成。7.8s
  2. 糖类是细胞的重要能源物质，其中葡萄糖是细胞生命活动所需要的主要能源物质，常被称为“生命的燃料”。9.8s
  3. 糖类还能构成细胞结构，比如纤维素是植物细胞壁的主要成分。6.2s
  4. 易错：糖类不都是能源物质——纤维素、核糖、脱氧核糖都不为细胞供能；几丁质还含有N。9.6s

单糖02#

单糖是不能水解的糖，可以被细胞直接吸收。六碳糖有葡萄糖、果糖、半乳糖；五碳糖有核糖和脱氧核糖。

单糖归属或功能
核糖RNA的组成成分
脱氧核糖DNA的组成成分
葡萄糖动植物细胞共有的单糖
高考怎么考
判断动植物细胞共有的糖。
易错点
单糖不能水解，可被细胞直接吸收；二糖必须水解成单糖才能被吸收。
解题方法
动植物细胞共有的是葡萄糖、核糖、脱氧核糖。
视频原话4 句
  1. 考点二，单糖。单糖是不能水解的糖，可以被细胞直接吸收。6.4s
  2. 六碳糖有葡萄糖、果糖、半乳糖；五碳糖有核糖和脱氧核糖。6.5s
  3. 核糖是RNA的组成成分，脱氧核糖是DNA的组成成分；葡萄糖是动植物细胞共有的单糖。8.9s
  4. 考法：判断动植物细胞共有的糖。解题方法：共有的是葡萄糖、核糖、脱氧核糖。8.6s

二糖03#

二糖由两分子单糖脱水缩合而成，必须水解成单糖才能被吸收。

二糖分布水解产物
蔗糖植物细胞一分子葡萄糖和一分子果糖
麦芽糖植物细胞两分子葡萄糖
乳糖动物细胞（人和动物乳汁中含量丰富）一分子葡萄糖和一分子半乳糖
高考怎么考
判断“蔗糖和麦芽糖的水解产物都只有葡萄糖”——错误，蔗糖水解为葡萄糖和果糖。
易错点
蔗糖不是还原糖，麦芽糖和乳糖是还原糖；二糖的水解产物都含有葡萄糖。
解题方法
按“蔗糖（葡+果）、麦芽糖（葡+葡）、乳糖（葡+半乳）”三组记水解产物。
视频原话4 句
  1. 考点三，二糖。二糖由两分子单糖脱水缩合而成，必须水解成单糖才能被吸收。8.6s
  2. 植物细胞中的二糖：蔗糖水解成一分子葡萄糖和一分子果糖；麦芽糖水解成两分子葡萄糖。8.9s
  3. 动物细胞中的二糖：乳糖，水解成一分子葡萄糖和一分子半乳糖，人和动物乳汁中含量丰富。9.1s
  4. 易错：蔗糖不是还原糖，麦芽糖和乳糖是还原糖；二糖的水解产物都含有葡萄糖。8.4s

多糖04#

多糖分布功能
淀粉植物细胞储能物质
糖原人和动物细胞，主要在肝脏和肌肉中储能物质
纤维素植物细胞壁主要成分，很难被人体消化

淀粉、糖原、纤维素的基本单位都是葡萄糖，但葡萄糖的连接方式不同，所以性质不同。

几丁质广泛存在于甲壳类动物和昆虫的外骨骼中，能与重金属离子结合，可用于废水处理。一些科学家把纤维素等其他糖类称为人类的“第七类营养素”。

高考怎么考
判断“淀粉、糖原、纤维素的单体都是葡萄糖”——正确。
易错点
肝糖原能分解补充血糖，肌糖原不能直接分解成葡萄糖；纤维素不是储能物质。
解题方法
多糖按“植物储能—淀粉；动物储能—糖原；植物结构—纤维素”分类，三者基本单位相同、连接方式不同。
视频原话5 句
  1. 考点四，多糖。淀粉是植物细胞中的储能物质，糖原是人和动物细胞中的储能物质，主要分布在肝脏和肌肉中。10.8s
  2. 纤维素是植物细胞壁的主要成分，很难被人体消化；一些科学家把纤维素等其他糖类称为人类的“第七类营养素”。10.3s
  3. 淀粉、糖原、纤维素的基本单位都是葡萄糖，但葡萄糖的连接方式不同，所以性质不同。8.3s
  4. 几丁质广泛存在于甲壳类动物和昆虫的外骨骼中，能与重金属离子结合，可用于废水处理。8.7s
  5. 易错：肝糖原能分解补充血糖，肌糖原不能直接分解成葡萄糖；纤维素不是储能物质。8.9s

脂质的种类与功能05#

脂质主要含C、H、O，有的还含有N和P；通常不溶于水，而溶于脂溶性有机溶剂。

脂质功能
脂肪细胞内良好的储能物质，还有保温、缓冲和减压的作用
磷脂构成细胞膜和多种细胞器膜的重要成分
固醇包括胆固醇、性激素和维生素D：胆固醇构成动物细胞膜，还参与血液中脂质的运输；维生素D促进钙和磷的吸收
高考怎么考
判断“胆固醇是构成动物细胞膜的重要成分”——正确。
易错点
性激素是固醇，不是蛋白质；所有细胞都含磷脂，因为所有细胞都有细胞膜。
解题方法
脂质记三大类：脂肪（储能）、磷脂（膜）、固醇（胆固醇、性激素、维生素D），再按功能逐个对号入座。
视频原话5 句
  1. 考点五，脂质的种类与功能。脂质主要含C、H、O，有的还含有N和P；通常不溶于水，而溶于脂溶性有机溶剂。11.4s
  2. 脂肪是细胞内良好的储能物质，还有保温、缓冲和减压的作用。6.2s
  3. 磷脂是构成细胞膜和多种细胞器膜的重要成分。4.9s
  4. 固醇包括胆固醇、性激素和维生素D：胆固醇构成动物细胞膜，还参与血液中脂质的运输；维生素D促进钙和磷的吸收。11.9s
  5. 易错：性激素是固醇，不是蛋白质；所有细胞都含磷脂，因为所有细胞都有细胞膜。8.2s

脂肪的组成06#

脂肪是由三分子脂肪酸与一分子甘油发生反应形成的酯，叫三酰甘油。

来源脂肪酸类型熔点室温状态
植物脂肪（大多）不饱和脂肪酸较低液态
动物脂肪（大多数）饱和脂肪酸较高固态
高考怎么考
考查脂肪的组成元素与结构单位，以及植物脂肪和动物脂肪的状态差异。
易错点
脂肪只含C、H、O，不含N、P；含N、P的是磷脂。
解题方法
组成记“三个脂肪酸 + 一个甘油”；状态记“不饱和—熔点低—液态，饱和—熔点高—固态”。
视频原话4 句
  1. 考点六，脂肪的组成。脂肪是由三分子脂肪酸与一分子甘油发生反应形成的酯，叫三酰甘油。9.5s
  2. 植物脂肪大多含不饱和脂肪酸，熔点较低，室温时呈液态。6.2s
  3. 大多数动物脂肪含饱和脂肪酸，熔点较高，室温时呈固态。6.1s
  4. 易错：脂肪只含C、H、O，不含N、P；含N、P的是磷脂。7.0s

糖类与脂肪比较07#

糖类与脂肪都由C、H、O组成，但脂肪中H的含量高，O的含量低。所以等质量的脂肪氧化分解时，消耗的氧气多，释放的能量多，产生的水也多。

比较项目糖类脂肪
元素组成C、H、OC、H、O，H的含量高、O的含量低
等质量氧化分解耗氧较少，释放能量较少耗氧多，释放能量多，产生的水也多

视频原话4 句
  1. 考点七，糖类与脂肪的比较。两者都由C、H、O组成，但脂肪中H的含量高，O的含量低。9.6s
  2. 所以等质量的脂肪氧化分解时，消耗的氧气多，释放的能量多，产生的水也多。7.8s
  3. 因此，脂肪是良好的储能物质；而糖类是主要的能源物质。6.0s

糖类和脂质的转化08#

血液中的葡萄糖除供细胞利用外，多余的部分可以合成糖原储存起来；如果葡萄糖还有富余，就可以转变成脂肪和某些氨基酸。糖类供应充足时，可以大量转化为脂肪。

而脂肪一般只在糖类供能不足时，才会分解供能，而且不能大量转化为糖类。

高考怎么考
解释“吃糖多也会发胖”，或判断“脂肪在细胞中可以大量转化为糖类”——错误。
易错点
脂肪并不是随时供能，只在糖类供能不足时才分解供能。
解题方法
记住转化是不对称的——糖能大量变脂肪，脂肪不能大量变糖。

  3. 而脂肪一般只在糖类供能不足时，才会分解供能，而且不能大量转化为糖类。7.6s
  4. 考法：解释“吃糖多也会发胖”。解题方法：记住转化是不对称的——糖能大量变脂肪，脂肪不能大量变糖。10.7s
