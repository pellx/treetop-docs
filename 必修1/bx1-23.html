动植物有丝分裂区别01#

动植物细胞有丝分裂的区别，在前期和末期。

时期植物细胞动物细胞
前期：纺锤体的形成从细胞两极发出纺锤丝由中心体发出星射线，中心粒在间期倍增
末期：细胞质的分裂在赤道板位置形成细胞板，扩展成细胞壁细胞膜从中部向内凹陷，缢裂成两个子细胞
高考怎么考
判断“动植物细胞有丝分裂的区别在中期和后期”——错误，区别在前期和末期。
易错点
低等植物细胞也有中心体；判断动物还是植物，最可靠的是看有无细胞壁和末期的分裂方式。
解题方法
按“前期看纺锤体来源、末期看细胞质如何分裂”两处区分，不要只凭是否有中心体判断。
视频原话4 句
  1. 考点一，动植物细胞有丝分裂的区别，在前期和末期。5.5s
  2. 前期纺锤体的形成：植物细胞从细胞两极发出纺锤丝；动物细胞由中心体发出星射线，中心粒在间期倍增。10.6s
  3. 末期细胞质的分裂：植物细胞在赤道板位置形成细胞板，扩展成细胞壁；动物细胞的细胞膜从中部向内凹陷，缢裂成两个子细胞。12.4s
  4. 易错：低等植物细胞也有中心体；判断动物还是植物，最可靠的是看有无细胞壁和末期的分裂方式。9.9s

有丝分裂的意义02#

有丝分裂将亲代细胞的染色体经过复制后，精确地平均分配到两个子细胞中。

这样就保持了亲子代细胞之间遗传的稳定性。

高考怎么考
说明有丝分裂对生物遗传的意义。
易错点
平均分配的是细胞核中的DNA；细胞质中的DNA，如线粒体DNA，是随机、不均等分配的。
解题方法
答意义：染色体复制后精确平均分配到子细胞，从而保持亲子代细胞间遗传的稳定性。
视频原话3 句
  1. 考点二，有丝分裂的意义。将亲代细胞的染色体经过复制后，精确地平均分配到两个子细胞中。9.4s
  2. 保持了亲子代细胞之间遗传的稳定性。3.7s
  3. 易错：平均分配的是细胞核中的DNA；细胞质中的DNA，如线粒体DNA，是随机、不均等分配的。10.5s

无丝分裂03#

无丝分裂的过程中没有出现纺锤丝和染色体的变化，所以叫无丝分裂。

过程：细胞核先延长，核的中部向内凹进，缢裂成两个细胞核；接着整个细胞从中部缢裂成两个子细胞。实例：蛙的红细胞的分裂。

高考怎么考
判断“蛙的红细胞进行无丝分裂，没有DNA复制”——错误，无丝分裂也有DNA复制。
易错点
无丝分裂也有DNA的复制；它是真核细胞的分裂方式，原核细胞进行的是二分裂；人的成熟红细胞不分裂。
解题方法
无丝分裂记两点：没有纺锤丝和染色体的变化，但仍有DNA复制；实例是蛙的红细胞。
视频原话4 句
  1. 考点三，无丝分裂。分裂过程中没有出现纺锤丝和染色体的变化，所以叫无丝分裂。8.5s
  2. 过程：细胞核先延长，核的中部向内凹进，缢裂成两个细胞核；接着整个细胞从中部缢裂成两个子细胞。10.0s
  3. 实例：蛙的红细胞的分裂。3.0s
  4. 易错：无丝分裂也有DNA的复制；它是真核细胞的分裂方式，原核细胞进行的是二分裂；人的成熟红细胞不分裂。10.8s

观察根尖实验步骤04#

步骤做法与目的
解离用盐酸和酒精1∶1混合的解离液，使组织中的细胞相互分离
漂洗用清水漂洗，洗去解离液，防止解离过度，也便于染色
染色用甲紫溶液或醋酸洋红液等碱性染料，使染色体着色
制片压片使细胞分散开，再用低倍镜找到分生区，换高倍镜观察

四个步骤的顺序固定：先解离，再漂洗，然后染色，最后制片观察。

高考怎么考
判断“实验步骤是解离、染色、漂洗、制片”——错误，应先漂洗再染色。
易错点
顺序是解离、漂洗、染色、制片，漂洗一定在染色之前；分生区细胞呈正方形、排列紧密。
解题方法
每一步的作用：解离使细胞分离，漂洗防解离过度并便于染色，染色使染色体着色，制片使细胞分散；观察时先低倍镜找分生区，再换高倍镜。
视频原话5 句
  1. 考点四，观察根尖分生区组织细胞的有丝分裂。解离：用盐酸和酒精1∶1混合的解离液，使组织中的细胞相互分离。11.7s
  2. 漂洗：用清水漂洗，洗去解离液，防止解离过度，也便于染色。6.6s
  3. 染色：用甲紫溶液或醋酸洋红液等碱性染料，使染色体着色。6.5s
  4. 制片：压片使细胞分散开，再用低倍镜找到分生区，换高倍镜观察。7.2s
  5. 易错：顺序是解离、漂洗、染色、制片，漂洗一定在染色之前；分生区细胞呈正方形、排列紧密。10.4s

实验结果分析05#

视野中大多数细胞处于分裂间期，因为间期在细胞周期中占的时间最长。

解离后细胞已经死亡，所以不能看到一个细胞连续分裂的过程，要寻找处于不同时期的细胞。

高考怎么考
判断“可以看到一个细胞连续分裂的全过程”——错误，解离后细胞已死亡。
易错点
视野中看到的是不同细胞处于不同时期的“定格”，不能把它们当作同一个细胞的连续变化。
解题方法
某时期细胞数占总数的比例，等于这一时期占细胞周期时间的比例，可以用来估算各时期的时长。
视频原话3 句
  1. 考点五，实验结果分析。视野中大多数细胞处于分裂间期，因为间期在细胞周期中占的时间最长。10.2s
  2. 解离后细胞已经死亡，所以不能看到一个细胞连续分裂的过程，要寻找处于不同时期的细胞。8.3s
  3. 解题方法：某时期细胞数占总数的比例，等于这一时期占细胞周期时间的比例，可以用来估算各时期的时长。9.9s

柱形图和曲线图06#

柱形图中，会变成0的是染色单体。

染色单体数量关系对应时期
为0染色体数等于核DNA数间期复制前、后期和末期
不为0染色体∶核DNA∶染色单体 = 1∶2∶2前期和中期

曲线图中，核DNA是斜线上升，因为DNA复制需要时间；染色体是垂直上升，因为着丝粒是一下子分裂的。

高考怎么考
根据柱形图或曲线图，判断各柱或各线分别代表染色体、核DNA还是染色单体，及其所处时期。
易错点
曲线上核DNA斜线上升、染色体垂直上升，不要把两条线互换。
解题方法
先找能变成0的是染色单体，再看有没有斜线区分核DNA和染色体。
视频原话5 句
  1. 考点六，柱形图和曲线图。柱形图中，会变成0的是染色单体。6.9s

  3. 染色单体不为0时，染色体∶核DNA∶染色单体 = 1∶2∶2，对应前期和中期。8.7s
  4. 曲线图中，核DNA是斜线上升，因为DNA复制需要时间；染色体是垂直上升，因为着丝粒是一下子分裂的。11.0s

  3. 判断三？错，无丝分裂也有DNA复制。判断四？错，要先漂洗再染色。8.8s
  4. 判断五？错，解离后细胞已经死亡。判断六？对。6.9s
  5. 六个考点串成一条线：前期末期看区别，解离漂洗染色制片。我们下期再见！8.1s
