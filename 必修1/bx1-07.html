核酸的种类与分布01#

核酸包括两大类：脱氧核糖核酸（DNA）和核糖核酸（RNA）。

核酸主要分布
DNA真核细胞中主要分布在细胞核，线粒体、叶绿体内也含有少量的DNA
RNA主要分布在细胞质中
高考怎么考
判断“DNA只分布在细胞核中”——错误，主要在细胞核，线粒体、叶绿体中也有。
易错点
是“主要”分布，不是“只”分布；原核细胞没有细胞核，DNA在拟核中。
解题方法
分布题抓“主要”二字：DNA主要在核、RNA主要在质，但线粒体、叶绿体中也有DNA，原核细胞的DNA在拟核。
视频原话4 句
  1. 考点一，核酸的种类和分布。核酸包括两大类：脱氧核糖核酸，DNA，和核糖核酸，RNA。9.8s
  2. 真核细胞的DNA主要分布在细胞核中，线粒体、叶绿体内也含有少量的DNA。7.7s
  3. RNA主要分布在细胞质中。3.1s
  4. 易错：是“主要”分布，不是“只”分布；原核细胞没有细胞核，DNA在拟核中。7.2s

核苷酸的组成02#

核酸的基本单位是核苷酸。一分子核苷酸由一分子磷酸、一分子五碳糖和一分子含氮碱基组成。

核酸链的构成
DNA通常由两条脱氧核苷酸链构成
RNA通常由一条核糖核苷酸链构成
高考怎么考
判断“核酸彻底水解的产物是核苷酸”——错误，彻底水解的产物是磷酸、五碳糖和含氮碱基。
易错点
核酸初步水解得到核苷酸，彻底水解得到磷酸、五碳糖和含氮碱基。
解题方法
区分“初步水解”与“彻底水解”：前者停在基本单位（核苷酸），后者继续拆成磷酸、五碳糖、含氮碱基三类小分子。
视频原话4 句
  1. 考点二，核苷酸的组成。核酸的基本单位是核苷酸。5.7s
  2. 一分子核苷酸由一分子磷酸、一分子五碳糖和一分子含氮碱基组成。6.7s
  3. 核苷酸连接成长链构成核酸：DNA通常由两条脱氧核苷酸链构成，RNA通常由一条核糖核苷酸链构成。10.9s
  4. 易错：核酸初步水解得到核苷酸，彻底水解得到磷酸、五碳糖和含氮碱基。7.9s

DNA与RNA的比较03#

DNA的基本单位是脱氧核苷酸，RNA的基本单位是核糖核苷酸，各有4种。

比较项目DNARNA
基本单位脱氧核苷酸核糖核苷酸
五碳糖脱氧核糖核糖
共有碱基A、G、CA、G、C
特有碱基T（胸腺嘧啶）U（尿嘧啶）
高考怎么考
判断“DNA与RNA的区别只在于碱基不同”——错误，五碳糖也不同。
易错点
区别有两处：五碳糖（脱氧核糖与核糖）和特有碱基（T与U），不能只答碱基。
解题方法
区分DNA和RNA，看五碳糖，或者看含T还是含U。
视频原话4 句
  1. 考点三，DNA与RNA的比较。基本单位：DNA是脱氧核苷酸，RNA是核糖核苷酸，各有4种。10.7s
  2. 五碳糖：DNA含脱氧核糖，RNA含核糖。5.0s
  3. 碱基：两者都有A、G、C；DNA特有T，胸腺嘧啶；RNA特有U，尿嘧啶。8.6s
  4. 解题方法：区分DNA和RNA，看五碳糖，或者看含T还是含U。7.1s

碱基与核苷酸种类04#

细胞生物同时含有DNA和RNA，病毒只含有一种核酸，DNA或RNA。

生物类型核酸碱基核苷酸五碳糖
细胞生物DNA和RNA5种8种2种
病毒DNA或RNA（一种）4种4种—
高考怎么考
判断“人体细胞中含有5种碱基、8种核苷酸”——正确。
易错点
碱基5种、核苷酸却有8种，因为A、G、C各对应两种核苷酸，T和U只各对应一种。
解题方法
先判断是细胞生物还是病毒：细胞生物答5、8，病毒只含一种核酸答4、4。
视频原话4 句
  1. 考点四，不同生物的碱基和核苷酸种类。细胞生物同时含有DNA和RNA。8.3s
  2. 所以细胞生物有5种碱基、8种核苷酸、2种五碳糖。5.7s
  3. 病毒只含有一种核酸，DNA或RNA，所以只有4种碱基、4种核苷酸。7.6s
  4. 易错：碱基5种、核苷酸却有8种，因为A、G、C各对应两种核苷酸，T和U只各对应一种。10.1s

生物的遗传物质05#

细胞生物，无论真核还是原核，遗传物质都是DNA。

病毒遗传物质
噬菌体DNA
HIV、烟草花叶病毒、新冠病毒RNA
高考怎么考
判断“细胞质中的遗传物质是RNA”——错误，细胞生物的遗传物质都是DNA。
易错点
“细胞质中的遗传物质是RNA”是错的，细胞生物的遗传物质只有DNA。
解题方法
细胞生物答DNA；病毒则按具体类型判断，噬菌体是DNA，HIV、烟草花叶病毒、新冠病毒是RNA。
视频原话3 句
  1. 考点五，生物的遗传物质。细胞生物，无论真核还是原核，遗传物质都是DNA。8.2s
  2. 病毒的遗传物质是DNA或RNA：噬菌体是DNA；HIV、烟草花叶病毒、新冠病毒是RNA。10.5s
  3. 易错：“细胞质中的遗传物质是RNA”是错的，细胞生物的遗传物质只有DNA。7.6s

核酸的功能06#

核酸是细胞内携带遗传信息的物质，在遗传、变异和蛋白质的生物合成中有极其重要的作用。

遗传信息储存在核苷酸的排列顺序中；对DNA来说，就是脱氧核苷酸的排列顺序。核苷酸虽然只有4种，但数量多、排列顺序千变万化，所以DNA能储存大量的遗传信息。

高考怎么考
DNA指纹用于刑侦和亲子鉴定；或判断“遗传信息储存在核苷酸的排列顺序中”——正确。
易错点
遗传信息不是由核苷酸的种类决定的：核苷酸只有4种，信息量来自数量多和排列顺序的千变万化。
解题方法
原理是不同个体DNA的脱氧核苷酸序列不同。
视频原话4 句
  1. 考点六，核酸的功能。核酸是细胞内携带遗传信息的物质，在遗传、变异和蛋白质的生物合成中有极其重要的作用。11.6s
  2. 遗传信息储存在核苷酸的排列顺序中；对DNA来说，就是脱氧核苷酸的排列顺序。8.4s
  3. 核苷酸虽然只有4种，但数量多、排列顺序千变万化，所以DNA能储存大量的遗传信息。9.0s
  4. 考法：DNA指纹用于刑侦和亲子鉴定。解题方法：原理是不同个体DNA的脱氧核苷酸序列不同。10.0s

单体与多聚体07#

生物大分子（多聚体）单体
多糖单糖
蛋白质氨基酸
核酸核苷酸

多糖、蛋白质、核酸都是生物大分子，由许多单体连接成多聚体。每个单体都以若干个相连的碳原子构成的碳链为基本骨架，所以说“碳是生命的核心元素”。

高考怎么考
判断“淀粉、糖原、纤维素的单体都是葡萄糖”，或指出某物质的单体是什么。
易错点
脂肪不是生物大分子，没有单体；淀粉、糖原、纤维素的单体都是葡萄糖。
解题方法
按“多糖—单糖、蛋白质—氨基酸、核酸—核苷酸”配对记忆；碰到脂肪直接排除。
视频原话4 句
  1. 考点七，生物大分子以碳链为骨架。多糖、蛋白质、核酸都是生物大分子，由许多单体连接成多聚体。11.0s
  2. 多糖的单体是单糖，蛋白质的单体是氨基酸，核酸的单体是核苷酸。6.5s
  3. 每个单体都以若干个相连的碳原子构成的碳链为基本骨架，所以说“碳是生命的核心元素”。8.4s
  4. 易错：脂肪不是生物大分子，没有单体；淀粉、糖原、纤维素的单体都是葡萄糖。8.4s
