渗透作用的条件01#

水分子等溶剂分子透过半透膜，从低浓度溶液一侧向高浓度溶液一侧扩散，叫作渗透作用。

  1. 要有半透膜。
  2. 半透膜两侧的溶液具有浓度差。
高考怎么考
判断某装置能否发生渗透作用，以及水分子的移动方向。
易错点
这里的浓度是物质的量浓度；质量分数相同的葡萄糖溶液和蔗糖溶液，葡萄糖溶液的物质的量浓度更大。
解题方法
先找半透膜，再比较膜两侧的物质的量浓度，水分子从低浓度一侧向高浓度一侧扩散。
视频原话3 句
  1. 考点一，渗透作用。水分子等溶剂分子透过半透膜，从低浓度溶液一侧向高浓度溶液一侧扩散，叫作渗透作用。11.2s
  2. 发生渗透作用有两个条件：一是要有半透膜，二是半透膜两侧的溶液具有浓度差。8.0s
  3. 易错：这里的浓度是物质的量浓度；质量分数相同的葡萄糖溶液和蔗糖溶液，葡萄糖溶液的物质的量浓度更大。10.7s

渗透装置分析02#

漏斗内装蔗糖溶液，烧杯中是清水，漏斗口封着一层半透膜。单位时间内进入漏斗的水分子多于出来的，漏斗内液面上升。

液面上升到一定高度后停止：此时液柱的压力与浓度差的作用相互平衡，水分子进出达到动态平衡。

高考怎么考
判断“渗透平衡时漏斗内外溶液浓度相等”——错误，漏斗内浓度仍高于烧杯。
易错点
平衡时漏斗内外浓度并不相等，漏斗内仍高于烧杯；水分子仍在双向移动，只是进出速率相等。
解题方法
液面上升看水分子净流向（进多于出）；液面停止是动态平衡，不是水分子停止移动。
视频原话4 句
  1. 考点二，渗透装置的分析。漏斗内装蔗糖溶液，烧杯中是清水，漏斗口封着一层半透膜。9.3s
  2. 单位时间内进入漏斗的水分子多于出来的，漏斗内液面上升。6.1s
  3. 液面上升到一定高度后停止：此时液柱的压力与浓度差的作用相互平衡，水分子进出达到动态平衡。9.7s
  4. 易错：平衡时漏斗内外浓度并不相等，漏斗内仍高于烧杯；水分子仍在双向移动，只是进出速率相等。10.4s

动物细胞吸水失水03#

动物细胞的细胞膜相当于一层半透膜。

外界溶液浓度与细胞质浓度水分子进出细胞变化
外界浓度低于细胞质浓度进多于出吸水膨胀，甚至涨破
外界浓度高于细胞质浓度出多于进失水皱缩
两者浓度相同进出平衡细胞形态不变（静脉输液要用生理盐水）
高考怎么考
红细胞放入不同浓度溶液中的形态变化。
易错点
动物细胞靠细胞膜充当半透膜，吸水过多会涨破，失水则皱缩，不会出现质壁分离。
解题方法
水往浓处流，先比较细胞内外的浓度。
视频原话4 句
  1. 考点三，动物细胞的吸水和失水。动物细胞的细胞膜相当于一层半透膜。7.4s
  2. 外界溶液浓度低于细胞质浓度时，细胞吸水膨胀，甚至涨破；外界浓度高于细胞质浓度时，细胞失水皱缩。10.7s
  3. 两者浓度相同时，水分子进出平衡，细胞形态不变，所以静脉输液要用生理盐水。8.5s
  4. 考法：红细胞放入不同浓度溶液中的形态变化。解题方法：水往浓处流，先比较细胞内外的浓度。9.8s

原生质层04#

成熟的植物细胞有中央大液泡，液泡内的液体叫细胞液。细胞膜和液泡膜，以及两层膜之间的细胞质，称为原生质层，相当于一层半透膜。

细胞壁是全透性的，而且伸缩性比原生质层小。

高考怎么考
判断“原生质层包括细胞膜、液泡膜和细胞核”——错误，是两层膜及两层膜之间的细胞质。
易错点
原生质层不包括细胞液，也不能把细胞壁算进去；起半透膜作用的是原生质层，不是细胞壁。
解题方法
原生质层 = 细胞膜 + 液泡膜 + 两层膜之间的细胞质；细胞壁全透、伸缩性小，不属于半透膜。
视频原话4 句
  1. 考点四，原生质层。成熟的植物细胞有中央大液泡，液泡内的液体叫细胞液。8.4s
  2. 细胞膜和液泡膜，以及两层膜之间的细胞质，称为原生质层，相当于一层半透膜。7.8s
  3. 细胞壁是全透性的，而且伸缩性比原生质层小。5.0s
  4. 易错：原生质层不包括细胞液，也不能把细胞壁算进去；起半透膜作用的是原生质层，不是细胞壁。9.7s

质壁分离及复原05#

探究植物细胞的吸水和失水，常用紫色洋葱鳞片叶的外表皮，液泡有颜色，便于观察。

操作现象结论
滴加0.3 g/mL的蔗糖溶液原生质层与细胞壁逐渐分离，液泡变小、颜色变深出现质壁分离
再滴加清水液泡逐渐变大出现质壁分离复原

整个实验用低倍镜观察三次，形成前后自身对照。

高考怎么考
判断“质壁分离过程中细胞液浓度逐渐增大”——正确（失水后液泡变小、颜色变深）。
易错点
本实验用低倍镜观察三次，形成的是同一细胞前后的自身对照。
解题方法
质壁分离的内因是原生质层的伸缩性大于细胞壁，外因是外界溶液浓度大于细胞液浓度。
视频原话5 句
  1. 考点五，探究植物细胞的吸水和失水。常用紫色洋葱鳞片叶的外表皮，液泡有颜色，便于观察。9.6s
  2. 滴加0.3 g/mL的蔗糖溶液，原生质层与细胞壁逐渐分离，出现质壁分离，液泡变小、颜色变深。10.2s
  3. 再滴加清水，液泡逐渐变大，出现质壁分离复原。5.3s
  4. 整个实验用低倍镜观察三次，形成前后自身对照。5.4s
  5. 解题方法：质壁分离的内因是原生质层的伸缩性大于细胞壁，外因是外界溶液浓度大于细胞液浓度。9.8s

应用与自动复原06#

质壁分离可以用来判断细胞的死活，死细胞不发生质壁分离；还可以估测细胞液浓度的范围。

把细胞放入一定浓度的KNO3溶液中，先发生质壁分离，随后会自动复原。因为K+和NO3-可以被细胞主动吸收，细胞液浓度升高，细胞又吸水；尿素、甘油、乙二醇溶液中也会自动复原。

高考怎么考
判断“动物细胞放入高浓度溶液会质壁分离”——错误，没有细胞壁，只会失水皱缩。
易错点
外界溶液浓度过高，细胞失水过多而死亡，就不能复原；动物细胞没有细胞壁，不会发生质壁分离。
解题方法
质壁分离后能否复原，先判断细胞是否存活，再看溶质能否被细胞吸收：KNO3、尿素、甘油、乙二醇溶液中会自动复原。
视频原话4 句
  1. 考点六，质壁分离的应用。可以判断细胞的死活，死细胞不发生质壁分离；还可以估测细胞液浓度的范围。10.3s
  2. 把细胞放入一定浓度的KNO3溶液中，先发生质壁分离，随后会自动复原。7.2s
  3. 因为K+和NO3-可以被细胞主动吸收，细胞液浓度升高，细胞又吸水；尿素、甘油、乙二醇溶液中也会自动复原。12.0s
  4. 易错：外界溶液浓度过高，细胞失水过多而死亡，就不能复原；动物细胞没有细胞壁，不会发生质壁分离。10.2s

自由扩散与协助扩散07#

物质以扩散方式进出细胞，不需要消耗细胞内化学反应释放的能量，叫作被动运输，包括自由扩散和协助扩散。

比较项目自由扩散协助扩散
方式通过简单的扩散作用进出细胞借助膜上的转运蛋白进出细胞
实例O2、CO2、甘油、乙醇、苯等葡萄糖进入红细胞；水分子更多地借助水通道蛋白进出
高考怎么考

载体与通道蛋白08#

转运蛋白分为载体蛋白和通道蛋白两类。

类型转运特点
载体蛋白只容许与自身结合部位相适应的分子或离子通过，每次转运时都会发生自身构象的改变
通道蛋白只容许大小、形状和电荷相适宜的分子或离子通过，分子或离子通过时不需要与通道蛋白结合
高考怎么考
判断“分子通过通道蛋白时需要与之结合”——错误，不需要与通道蛋白结合。
易错点
协助扩散的速率除了受浓度差影响，还受转运蛋白数量的限制，所以曲线最后会趋于平缓。
解题方法
区分两类蛋白：载体蛋白要结合并发生构象改变，通道蛋白按大小、形状、电荷筛选且不与物质结合。
视频原话4 句

  2. 载体蛋白只容许与自身结合部位相适应的分子或离子通过，每次转运时都会发生自身构象的改变。9.5s
  3. 通道蛋白只容许大小、形状和电荷相适宜的分子或离子通过，分子或离子通过时不需要与通道蛋白结合。10.2s
  4. 易错：协助扩散的速率除了受浓度差影响，还受转运蛋白数量的限制，所以曲线最后会趋于平缓。9.8s
