光合作用与能量转化（三） · 曲线分析

视频原话 · 导读3 句
  1. 同学们好！这节课梳理人教版必修一第五章第四节的第三部分——影响光合作用的因素及应用。9.0s
  2. 高考常考光照强度、CO2浓度等因素的曲线分析，以及总光合与净光合的计算。8.2s
  3. 我们按八个考点梳理，每个考点都讲清楚怎么考、怎么做。5.5s

光合作用强度01#

植物在单位时间内通过光合作用制造糖类的数量
原料的消耗量
CO2 的吸收量
产物的生成量
O2 的释放量、有机物的积累量
易错
实际测得的 CO2 吸收量、O2 释放量是净光合速率（同时在进行呼吸作用）
视频原话3 句
  1. 考点一，光合作用强度。指植物在单位时间内通过光合作用制造糖类的数量。8.1s
  2. 可以用单位时间内原料的消耗量，如CO2的吸收量，或产物的生成量，如O2的释放量、有机物的积累量来表示。10.5s
  3. 易错：实际测得的CO2吸收量或O2释放量是净光合速率，因为同时还在进行呼吸作用。9.4s

叶片上浮实验02#

  1. 打出圆形小叶片
  2. →抽出叶内气体叶片沉到水底
  3. →放入富含 CO2 的清水
  1. 不同强度光照调节光源距离
  2. →光合作用产生 O2
  3. →叶片上浮浮起越多越快 → 光合越强
解题方法
自变量：光照强度；因变量：叶片上浮的数量或时间；抽气是为了排除原有气体的干扰
视频原话4 句
  1. 考点二，探究光照强度对光合作用强度的影响。用打孔器打出圆形小叶片，用注射器抽出叶片内的气体，叶片沉到水底。12.3s
  2. 把小叶片放入富含CO2的清水中，用不同强度的光照射，比如调节光源与烧杯的距离。8.6s
  3. 光合作用产生O2，叶片会浮起；单位时间内浮起的叶片越多，光合作用越强。8.0s
  4. 解题方法：自变量是光照强度，因变量是叶片上浮的数量或时间；抽气是为了排除叶片内原有气体的干扰。10.3s

光补偿点与饱和点03#

  • 光照为 0：只进行呼吸作用
  • 光补偿点：光合速率 ＝ 呼吸速率
  • 光饱和点：光合速率不再随光照增加
  • 阴生植物：两个点都较低
易错
植物处于光补偿点时，叶肉细胞的光合速率大于其自身呼吸速率
视频原话4 句
  1. 考点三，光照强度的影响曲线。纵轴是CO2吸收量，光照为0时只进行呼吸作用，曲线在横轴以下。10.8s
  2. 光合速率等于呼吸速率时的光照强度，叫光补偿点。5.2s
  3. 光照增强到一定程度后，光合速率不再增加，这时的光照强度叫光饱和点。7.4s
  4. 考法：阴生植物的光补偿点和光饱和点都比阳生植物低。易错：光补偿点时，叶肉细胞的光合速率大于它自身的呼吸速率。12.2s

总光合与净光合04#

总光合速率 ＝ 净光合速率 ＋ 呼吸速率
类型O2CO2有机物
总光合产生、制造固定制造、生成
净光合释放吸收积累
呼吸速率黑暗中吸收黑暗中释放黑暗中消耗
解题方法
先看关键词判断总还是净；植物能否生长，看净光合速率是否大于 0
视频原话4 句
  1. 考点四，总光合速率与净光合速率。总光合速率 = 净光合速率 + 呼吸速率。8.4s
  2. 表示总光合的词：产生、制造O2或有机物，固定CO2；表示净光合的词：释放O2、吸收CO2、积累有机物。12.0s
  3. 黑暗中测得的CO2释放量，就是呼吸速率。4.7s
  4. 解题方法：先看关键词判断是总还是净；植物能否生长，看净光合速率是否大于0。8.7s

二氧化碳浓度05#

  • 一定范围内，CO2 浓度↑ → 光合作用↑
  • 达到饱和点后不再增加
  • 补偿点：光合速率 ＝ 呼吸速率
考法
温室增施有机肥（微生物分解产生 CO2）、通风，都能补充 CO2
视频原话3 句
  1. 考点五，CO2浓度的影响。一定范围内，光合作用强度随CO2浓度增大而增大，达到CO2饱和点后不再增加。12.0s
  2. CO2浓度过低时，光合速率小于呼吸速率；两者相等时的CO2浓度，叫CO2补偿点。9.6s
  3. 考法：温室中增施有机肥，微生物分解有机物产生CO2；也可以通风补充CO2。9.0s

温度水和矿质元素06#

  1. 1温度影响酶的活性，曲线先升后降
  2. 2水缺水 → 气孔关闭 → CO2 吸收减少
  3. 3矿质元素Mg：叶绿素的成分；N：酶、ATP、NADPH 的组成元素
解题方法
多因素曲线：上升段限制因素是横坐标所示因素；平台段限制因素是其他因素
视频原话4 句
  1. 考点六，温度、水和矿质元素。温度通过影响酶的活性影响光合作用，曲线先升后降。9.3s
  2. 缺水时叶片气孔关闭，CO2吸收减少，光合作用减弱。6.4s
  3. 矿质元素：如Mg是叶绿素的组成成分，N是酶、ATP、NADPH的组成元素。7.5s
  4. 解题方法：多因素曲线中，上升段的限制因素是横坐标所示因素；到达平台后，限制因素是其他因素。10.2s

午休与一昼夜曲线07#

夏季晴天光合速率
密闭容器中 CO2 浓度（一昼夜）
解题方法
一昼夜终点 CO2 浓度低于起点 → 有机物有积累，植物能生长
视频原话4 句
  1. 考点七，两类典型曲线。夏季晴天中午，温度高、蒸腾作用强，气孔部分关闭，CO2吸收减少，光合速率下降，出现“午休”现象。13.6s
  2. 密闭容器中一昼夜的CO2浓度：曲线的最高点和最低点，对应光合速率等于呼吸速率的时刻。9.3s
  3. 最高点之前，呼吸大于光合，CO2浓度上升；之后光合大于呼吸，CO2浓度下降，直到最低点。10.5s
  4. 解题方法：比较一昼夜首尾的CO2浓度，终点低于起点，说明有机物有积累，植物能生长。9.2s

光合原理的应用08#

  1. 1合理密植充分利用光能，避免叶片相互遮挡
  2. 2间作套种充分利用光能
  3. 3温室适当增加光照、补充 CO2
  4. 4昼夜温差白天适宜温度、夜晚低温 → 有机物积累多
易错
补光用红光或蓝紫光；阴天温室应适当降温，减少呼吸消耗
视频原话4 句
  1. 考点八，光合作用原理的应用。合理密植：充分利用光能，又避免叶片相互遮挡。8.4s
  2. 间作套种，充分利用光能；温室中适当增加光照、补充CO2。6.8s
  3. 适当提高昼夜温差：白天温度适宜，光合作用强；夜晚温度低，呼吸作用弱，有机物积累多。9.2s
  4. 易错：温室补光用红光或蓝紫光；阴天光照弱时，温室应适当降低温度，减少呼吸消耗。9.1s

易错速查✓

  1. 1测得的O2释放量代表总光合速率

  2. 2阴生植物的光补偿点比阳生植物高
    说法错误：阴生植物的光补偿点较低
  3. 3总光合速率＝净光合速率＋呼吸速率
    说法正确。
  4. 4夏季中午光合速率下降是因为光照太弱
    说法错误：气孔部分关闭，CO2吸收减少
  5. 5增施有机肥可以为植物提供CO2
    说法正确。
  6. 6夜间提高温度有利于有机物积累
    说法错误：夜间适当降温，减少呼吸消耗
