光合作用与能量转化（一） · 色素的提取和分离

视频原话 · 导读3 句
  1. 同学们好！这节课梳理人教版必修一第五章第四节的第一部分——捕获光能的色素和结构。8.5s
  2. 高考常考色素提取和分离实验、色素带和异常结果分析，以及色素的吸收光谱。8.1s
  3. 我们按七个考点梳理，每个考点都讲清楚怎么考、怎么做。5.6s

提取和分离的原理01#

提取
色素能溶解在有机溶剂无水乙醇中
分离（纸层析法）
各色素在层析液中溶解度不同：溶解度高的扩散快
易错
提取用无水乙醇，分离用层析液，两者不能混用
视频原话3 句
  1. 考点一，绿叶中色素的提取和分离。提取的原理：色素能够溶解在有机溶剂无水乙醇中。8.9s
  2. 分离的原理：不同色素在层析液中的溶解度不同，溶解度高的随层析液在滤纸上扩散得快，反之则慢。9.6s
  3. 易错：提取用无水乙醇，分离用层析液，别混；分离的方法叫纸层析法。7.5s

实验步骤与试剂02#

  1. 1研磨SiO2：研磨充分；CaCO3：防止色素被破坏；无水乙醇：溶解色素
  2. 2过滤单层尼龙布过滤，收集滤液
  3. 3画滤液细线细、直、齐；干后重复画一两次 → 色素多而集中
  4. 4层析层析液不能没及滤液细线（否则色素溶入层析液）
解题方法
SiO2 助研磨，CaCO3 护色素，无水乙醇溶色素，层析液分色素
视频原话5 句
  1. 考点二，实验步骤。研磨时加入SiO2，有助于研磨充分；加入CaCO3，防止研磨中色素被破坏。10.7s
  2. 研磨后用单层尼龙布过滤，收集滤液。4.2s
  3. 画滤液细线要细、直、齐，待滤液干后再画一两次，使色素多而集中。7.2s
  4. 层析时，层析液不能没及滤液细线，否则色素会溶解到层析液中。6.6s
  5. 解题方法：一种试剂一个作用——SiO2助研磨，CaCO3护色素，无水乙醇溶色素，层析液分色素。9.8s

四条色素带03#

解题方法
从上到下：胡、黄、a、b；宽度（含量）：叶绿素a ＞ 叶绿素b ＞ 叶黄素 ＞ 胡萝卜素
视频原话4 句
  1. 考点三，实验结果。滤纸条上从上到下依次是：胡萝卜素，橙黄色；叶黄素，黄色；9.2s
  2. 叶绿素a，蓝绿色；叶绿素b，黄绿色。4.5s
  3. 最宽的是叶绿素a，含量最多；最窄的是胡萝卜素；胡萝卜素在层析液中溶解度最高，扩散最快。9.5s
  4. 解题方法：顺序记“胡、黄、a、b”；宽度看含量：叶绿素a、叶绿素b、叶黄素、胡萝卜素依次减少。10.8s

异常结果分析04#

异常现象可能原因
色素带颜色都很浅研磨不充分、未加 SiO2、无水乙醇过多、画线次数少
叶绿素带很窄或没有未加 CaCO3（叶绿素被破坏），或选用了发黄的叶片
没有色素带层析液没及滤液细线；或用水代替了无水乙醇
解题方法
对照每一步的作用：缺了哪一步，就出现哪种异常
视频原话4 句
  1. 考点四，异常结果分析。色素带颜色都很浅：可能是研磨不充分、未加SiO2、无水乙醇加得过多，或画线次数太少。12.1s
  2. 叶绿素带很窄甚至没有：可能是未加CaCO3，叶绿素被破坏；或者选用了发黄的叶片。8.3s
  3. 没有色素带：可能是层析液没及了滤液细线，或者用水代替了无水乙醇。6.8s
  4. 解题方法：对照每一步的作用，缺了哪一步，就出现哪种异常。5.9s

色素的吸收光谱05#

  • 叶绿素：主要吸收蓝紫光和红光
  • 类胡萝卜素：主要吸收蓝紫光
  • 绿光吸收最少，被反射 → 叶片呈绿色
考法
温室补光选红光或蓝紫光；类胡萝卜素不吸收红光
视频原话4 句
  1. 考点五，色素的吸收光谱。叶绿素a和叶绿素b主要吸收蓝紫光和红光。7.6s
  2. 胡萝卜素和叶黄素，也就是类胡萝卜素，主要吸收蓝紫光。5.7s
  3. 色素对绿光吸收最少，绿光被反射出来，所以叶片呈绿色。6.4s
  4. 考法：温室补光选红光或蓝紫光，不用绿光。易错：类胡萝卜素不吸收红光。8.3s

叶绿体的结构06#

  • 双层膜；基粒由类囊体堆叠而成
  • 四种色素都在类囊体薄膜上
  • 类囊体薄膜上和基质中有许多与光合作用有关的酶
解题方法
基粒、类囊体极大地扩展了受光面积：结构与功能相适应
视频原话4 句
  1. 考点六，叶绿体的结构适于进行光合作用。叶绿体有双层膜，内部有许多基粒，每个基粒由类囊体堆叠而成。10.8s
  2. 吸收光能的四种色素，都分布在类囊体的薄膜上。4.8s
  3. 类囊体薄膜上和叶绿体基质中，含有许多进行光合作用所必需的酶。6.7s
  4. 解题方法：基粒和类囊体极大地扩展了受光面积，体现了结构与功能相适应。7.5s

恩格尔曼实验07#

结论
叶绿体能吸收光能用于光合作用放氧；结合其他证据，得出叶绿体是光合作用的场所
三棱镜分光
细菌主要聚集在红光和蓝紫光区域
解题方法
水绵叶绿体螺旋带状便于观察；黑暗、无空气是为了排除光和氧气的干扰
视频原话5 句
  1. 考点七，恩格尔曼的实验。把载有水绵和需氧细菌的临时装片，放在没有空气的黑暗环境里，用极细的光束照射。10.7s
  2. 需氧细菌只向叶绿体被光束照射到的部位集中；如果完全暴露在光下，细菌就分布在叶绿体所有受光的部位。10.2s
  3. 结论：叶绿体能吸收光能用于光合作用放氧；结合其他证据，得出叶绿体是光合作用的场所。9.2s
  4. 他还用透过三棱镜的光照射水绵，发现细菌主要聚集在红光和蓝紫光区域。7.2s
  5. 解题方法：选水绵是因为它的叶绿体呈螺旋带状，便于观察；黑暗、无空气是为了排除光和氧气的干扰。10.3s

易错速查✓

先自己判断，再点按钮查看对错与解析。

  1. 1提取色素用层析液，分离色素用无水乙醇
    说法错误：提取用无水乙醇，分离用层析液
  2. 2加入CaCO3是为了研磨充分
    说法错误：CaCO3防止色素被破坏，SiO2助研磨
  3. 3滤纸条上最宽的色素带是叶绿素a
    说法正确。
  4. 4类胡萝卜素主要吸收红光和蓝紫光
    说法错误：类胡萝卜素主要吸收蓝紫光
  5. 5光合色素分布在叶绿体基质中
    说法错误：分布在类囊体的薄膜上
  6. 6恩格尔曼实验证明氧气由叶绿体释放
    说法正确。
