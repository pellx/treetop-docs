基因工程的概念01#

基因工程：按照人们的愿望，通过转基因等技术，赋予生物以新的遗传特性，创造出更符合人们需要的新的生物类型和生物产品
在 DNA 分子水平上设计和施工 → 又叫重组 DNA 技术
限制酶
分子手术刀
DNA 连接酶
分子缝合针
载体
分子运输车
易错
载体不是酶；基因工程的原理是基因重组，能定向改造性状、打破物种界限
视频原话4 句
  1. 考点一，基因工程的概念。它是指按照人们的愿望，通过转基因等技术，赋予生物以新的遗传特性，创造出更符合人们需要的新的生物类型和生物产品。14.2s
  2. 基因工程是在DNA分子水平上进行设计和施工的，所以又叫作重组DNA技术。8.2s
  3. 它需要三种基本工具：限制酶是“分子手术刀”，DNA连接酶是“分子缝合针”，载体是“分子运输车”。9.4s
  4. 易错：载体不是酶；基因工程的原理是基因重组，能定向改造生物的遗传性状，并且能打破物种界限。9.9s

限制酶02#

来源：主要从原核生物中分离纯化
作用：识别双链 DNA 的特定核苷酸序列，断开每条链特定部位的磷酸二酯键
识别序列：大多数由 6 个核苷酸组成，也有 4 个、8 个等
易错
限制酶切的是磷酸二酯键，不是氢键；在原核生物中的作用是切割外源 DNA，保护自身
视频原话5 句
  1. 考点二，限制性内切核酸酶，简称限制酶。它主要是从原核生物中分离纯化出来的。8.5s
  2. 限制酶能够识别双链DNA分子的特定核苷酸序列，并且使每一条链中特定部位的磷酸二酯键断开。9.4s
  3. 大多数限制酶的识别序列由6个核苷酸组成，也有少数由4个、8个或其他数量的核苷酸组成。9.1s
  4. 比如EcoRI，识别的序列是GAATTC，在G和A之间切开。7.1s
  5. 易错：限制酶切的是磷酸二酯键，不是氢键；它在原核生物中的作用是切割外源DNA，保护自身。9.7s

黏性末端与平末端03#

解题方法
同一种限制酶切出的黏性末端一定能连接；不同的限制酶，只要末端碱基互补也能连接
视频原话4 句
  1. 考点三，黏性末端和平末端。限制酶在识别序列的中心轴线两侧将DNA两条链分别切开时，产生黏性末端。11.3s
  2. 在中心轴线处切开时，产生的是平末端，比如SmaI。5.7s
  3. 限制酶的识别序列大多是回文序列：两条链从5′到3′方向读，碱基顺序相同。8.6s
  4. 考法：给出识别序列，问末端类型或能否连接。解题方法：同一种限制酶切出的黏性末端一定能互补连接；不同的限制酶，只要末端碱基互补也能连接。15.0s

DNA连接酶04#

作用：将两个 DNA 片段之间的磷酸二酯键连接起来（“分子缝合针”）
比较项目E. coli DNA 连接酶T4 DNA 连接酶
来源大肠杆菌T4 噬菌体
连接黏性末端能能
连接平末端不能能（效率较低）
易错
DNA 连接酶连接的是两个 DNA 片段；把单个脱氧核苷酸连到链上的是 DNA 聚合酶
视频原话4 句
  1. 考点四，DNA连接酶。它把两个DNA片段之间的磷酸二酯键连接起来。7.6s
  2. E. coli DNA连接酶，来源于大肠杆菌，只能连接黏性末端。6.1s
  3. T​4 DNA连接酶，来源于T​4噬菌体，黏性末端和平末端都能连接，但连接平末端的效率比较低。9.6s
  4. 易错：DNA连接酶连接的是两个DNA片段，不能把单个脱氧核苷酸连到DNA链上，那是DNA聚合酶的工作。11.4s

质粒载体05#

质粒：裸露、结构简单、独立于细胞核或拟核 DNA 之外，具有自我复制能力的环状双链 DNA
① 能在受体细胞中自我复制，或整合到受体 DNA 上随之复制
② 有一个至多个限制酶切割位点，供外源 DNA 插入
③ 有特殊的标记基因，便于筛选重组 DNA 分子
易错
质粒不是细胞器，酵母菌等真核生物也有；载体对受体细胞应无害
视频原话5 句
  1. 考点五，载体——质粒。质粒是一种裸露的、结构简单、独立于真核细胞细胞核或原核细胞拟核DNA之外，并具有自我复制能力的环状双链DNA分子。14.5s
  2. 作为载体，必须具备：第一，能在受体细胞中进行自我复制，或整合到受体DNA上随之复制。9.4s
  3. 第二，有一个至多个限制酶切割位点，供外源DNA片段插入。6.0s
  4. 第三，有特殊的标记基因，比如抗生素抗性基因，便于重组DNA分子的筛选。8.0s
  5. 易错：质粒不是细胞器，也不只存在于细菌中，酵母菌等真核生物也有；载体对受体细胞应无害。9.3s

其他载体06#

质粒
最常用
噬菌体
侵染细菌的病毒
动植物病毒
侵染动植物细胞
人工改造
载体往往在天然载体基础上改造：病毒去除致病性，保留侵染宿主细胞、整合 DNA 的能力
解题方法
判断能否作载体，看三个条件：能复制、有切点、有标记
视频原话4 句
  1. 考点六，其他载体。除了质粒，常用的载体还有噬菌体和动植物病毒。7.5s
  2. 在基因工程中使用的载体，往往是在天然载体的基础上经过人工改造的。6.8s
  3. 比如作为载体的病毒，要去除致病性，保留侵染宿主细胞和把DNA整合进去的能力。8.4s
  4. 解题方法：判断能不能作载体，就看三个条件——能复制、有切点、有标记。7.6s

DNA的粗提取与鉴定07#

原理一
DNA 不溶于酒精，某些蛋白质溶于酒精
原理二
DNA 能溶于 2 mol/L 的 NaCl 溶液
洋葱研磨
→
过滤取上清液
→
加等体积预冷酒精
→
白色丝状物（DNA）
溶于 2 mol/L NaCl
→
加二苯胺试剂
→
沸水浴加热
→
溶液变蓝
说明含有 DNA
易错
不选哺乳动物成熟红细胞（无细胞核）；二苯胺鉴定要沸水浴，并设置不加 DNA 的对照
视频原话5 句
  1. 考点七，探究实践：DNA的粗提取与鉴定。原理一：DNA不溶于酒精，但某些蛋白质溶于酒精，可以初步分离DNA和蛋白质。13.0s
  2. 原理二：DNA能溶于物质的量浓度为 2 mol/L 的 NaCl 溶液。6.2s
  3. 步骤：洋葱研磨、过滤，取上清液；加入等体积的、预冷的酒精，析出白色丝状物，就是粗提取的DNA。10.6s
  4. 鉴定：把丝状物溶于NaCl溶液，加入二苯胺试剂，沸水浴加热，溶液变成蓝色。8.3s
  5. 易错：不选哺乳动物成熟红细胞，因为它没有细胞核；二苯胺鉴定要沸水浴，而且要设置不加DNA的对照。10.2s

几种酶的比较08#

酶作用的键作用对象 / 结果
限制酶断开磷酸二酯键在特定序列处切割 DNA

解题方法
先问作用的键，再问作用的对象：是 DNA 片段，还是单个核苷酸
视频原话5 句
  1. 考点八，几种酶的比较。限制酶：断开特定部位的磷酸二酯键。6.6s
  2. DNA连接酶：连接两个DNA片段之间的磷酸二酯键。5.8s
  3. DNA聚合酶：把单个脱氧核苷酸加到已有DNA链的3′端，形成磷酸二酯键。7.9s
  4. {解旋酶|brown}：断开两条链之间的{氢键|brown}。3.6s
  5. 解题方法：先问作用的键，再问作用的对象——是片段还是单个核苷酸。7.0s
