适应的普遍与相对01#

适应：形态结构适合完成一定的功能；形态结构及功能适合该生物在一定环境中生存和繁殖
普遍性
枯叶蝶像枯叶；仙人掌叶变成刺；雷鸟冬季换白羽
相对性
降雪推迟时，白色雷鸟在褐色地面上反而显眼
考法
适应的相对性来自遗传的稳定性与环境的不断变化之间的矛盾
视频原话4 句
  1. 考点一，适应：生物的形态结构适合于完成一定的功能，生物的形态结构及其功能适合于该生物在一定的环境中生存和繁殖。11.8s
  2. 适应具有普遍性：比如枯叶蝶像枯叶，仙人掌的叶变成刺，雷鸟冬季换上白色羽毛。8.4s
  3. 适应又具有相对性：雷鸟冬季白羽，如果降雪推迟，白色的雷鸟在褐色的地面上反而很显眼。9.2s
  4. 考法：适应的相对性来自遗传的稳定性与环境的不断变化之间的矛盾。6.8s

拉马克的进化学说02#

  1. 1主张生物由更古老的生物进化而来，由低等到高等
  2. 2核心用进废退、获得性遗传
  1. 经常伸长脖子吃高处树叶
  2. →脖子变长（用进）
  3. →遗传给后代（获得性遗传）
解题方法
出现“为了”“经常使用”“环境导致产生某种变异” → 多为拉马克的观点
视频原话4 句
  1. 考点二，拉马克的进化学说。他认为生物是由更古老的生物进化来的，由低等到高等逐渐进化。9.2s
  2. 核心观点：用进废退和获得性遗传。器官经常使用就发达，不用就退化；这种后天获得的性状能遗传给后代。11.4s
  3. 例：长颈鹿的祖先经常伸长脖子吃高处的树叶，脖子越来越长，并遗传给后代。8.0s
  4. 解题方法：说法中出现“为了”“经常使用”“环境导致产生某种变异”，多半是拉马克的观点。8.3s

达尔文自然选择学说03#

  1. 1过度繁殖生物都有很强的繁殖能力 —— 前提
  2. 2生存斗争资源有限，为生存而斗争 —— 动力
  3. 3遗传变异个体间存在有利或不利变异 —— 内因
  4. 4适者生存有利变异个体存活并留下后代 —— 结果
考法
过度繁殖是前提，生存斗争是动力，遗传变异是内因，适者生存是结果
视频原话5 句
  1. 考点三，达尔文的自然选择学说，可以概括为四点。第一，过度繁殖：生物都有很强的繁殖能力。9.4s
  2. 第二，生存斗争：资源有限，个体之间为生存而斗争。5.9s
  3. 第三，遗传变异：个体之间存在差异，有的变异有利，有的不利。6.5s
  4. 第四，适者生存：具有有利变异的个体容易存活并留下后代，不利变异的个体被淘汰。8.4s
  5. 考法：过度繁殖是前提，生存斗争是动力，遗传变异是内因，适者生存是结果。8.2s

适应的形成04#

  1. 祖先中有颈长、颈短的变异可遗传变异，本来就有
  2. 食物缺乏 →颈长的存活繁殖，颈短的被淘汰自然选择
  1. 有利变异逐代积累
  2. 一代代选择 →形成长颈鹿
考法
适应是自然选择的结果；可遗传的有利变异和环境的定向选择是适应形成的必要条件
视频原话4 句
  1. 考点四，适应的形成。长颈鹿祖先中原本就有颈长的和颈短的，这是可遗传的变异。8.6s
  2. 食物缺乏时，颈长的能吃到高处的树叶，更容易存活和繁殖；颈短的被淘汰。7.5s
  3. 经过一代代自然选择，有利变异逐代积累，就形成了长颈鹿。5.9s
  4. 考法：适应是自然选择的结果；群体中出现可遗传的有利变异和环境的定向选择，是适应形成的必要条件。10.4s

达尔文学说的评价05#

意义
摆脱神学束缚；统一性源于共同祖先，多样性和适应性是进化的结果
局限性
① 不能科学解释遗传和变异的本质
② 局限于个体水平
③ 强调渐变，难以解释物种大爆发
易错
现代生物进化理论：进化的基本单位是种群，不是个体
视频原话4 句
  1. 考点五，达尔文学说的意义：使生物学第一次摆脱了神学的束缚，揭示了生物界的统一性是由于所有生物都有共同祖先，多样性和适应性是进化的结果。13.8s
  2. 局限性：对遗传和变异的本质不能做出科学的解释。5.3s
  3. 对生物进化的解释局限于个体水平；强调物种形成都是渐变的结果，不能很好地解释物种大爆发等现象。10.1s
  4. 易错：现代生物进化理论认为进化的基本单位是种群，不是个体——这是对达尔文学说的发展。8.9s

变异在前选择在后06#

变异在前，选择在后
  1. 害虫中本来就有抗药个体变异不定向
  2. 喷洒农药 →不抗药的被杀死农药起选择作用
  3. 繁殖 →抗药基因频率逐代升高
易错
“农药使害虫产生抗药性变异”✗ —— 变异不定向，环境只起选择作用
视频原话4 句
  1. 考点六，最常考的易错点：变异在前，选择在后。5.2s
  2. 以害虫抗药性为例：害虫群体中本来就存在抗药性个体，农药只是把不抗药的个体杀死。8.7s
  3. 抗药个体存活并繁殖，抗药基因的频率逐代升高，农药效果越来越差。6.8s
  4. 易错：“农药使害虫产生了抗药性变异”是错的。变异是不定向的，环境只起选择作用。8.9s

易错速查✓

先自己判断，再点按钮查看对错与解析。

  1. 1适应具有普遍性，也具有相对性
    说法正确。
  2. 2“长颈鹿的长颈是经常伸长脖子吃高处树叶的结果”是拉马克的观点
    说法正确。
  3. 3达尔文认为环境使生物产生了适应性变异
    说法错误：变异是不定向的，环境起选择作用
  4. 4达尔文科学地解释了遗传和变异的本质
    说法错误：这是达尔文学说的局限性
  5. 5农药使害虫产生了抗药性突变
    说法错误：抗药性变异原本就存在，农药只起选择作用
  6. 6自然选择直接作用于个体的表型
    说法正确。

视频原话 · 易错速查5 句
