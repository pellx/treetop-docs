协同进化的概念01#

不同物种之间
捕食、竞争、互利共生等相互影响
生物与无机环境之间
生物改变环境，环境选择生物
结果：出现千姿百态的物种，形成多种多样的生态系统
易错
协同进化不只发生在生物之间；同种生物之间的斗争不属于协同进化
视频原话3 句
  1. 考点一，协同进化：不同物种之间、生物与无机环境之间在相互影响中不断进化和发展。8.9s
  2. 通过漫长的协同进化过程，地球上不仅出现了千姿百态的物种，而且形成了多种多样的生态系统。8.8s
  3. 易错：协同进化不只发生在生物之间，生物与无机环境之间也有；同种生物之间的斗争不属于协同进化。10.1s

协同进化的实例02#

  1. 1兰花与蛾花距细长 → 推测有口器同样细长的昆虫；约 50 年后发现了这种蛾
  2. 2捕食者与猎物猎豹与羚羊越跑越快；收割理论：捕食者的存在有利于增加物种多样性
  3. 3生物与环境光合生物产生氧气 → 为好氧生物的出现创造条件
考法
判断是否属于协同进化：看是否是两者相互影响、共同变化
视频原话4 句
  1. 考点二，协同进化的实例。达尔文发现一种兰花长着细长的花距，他推测一定有口器同样细长的昆虫为它传粉，约 50 年后果然发现了这种蛾。14.0s
  2. 捕食者和猎物：猎豹越跑越快，羚羊也越跑越快。斯坦利的“收割理论”认为，捕食者的存在有利于增加物种多样性。11.1s
  3. 生物与环境：最早的光合生物产生了氧气，使大气中出现氧气，为好氧生物的出现创造了条件。9.4s
  4. 考法：判断实例是否属于协同进化，看是否是两者相互影响、共同变化。7.5s

生物多样性三层次03#

遗传多样性
同种生物不同个体之间基因的差异
也叫基因多样性
物种多样性
地球上生物种类的丰富程度
生态系统多样性
生境、生物群落和生态过程的多样
易错
生物多样性的形成不只是新物种的形成，还包括遗传多样性和生态系统多样性
视频原话3 句
  1. 考点三，生物多样性的三个层次：遗传多样性、物种多样性、生态系统多样性。8.0s
  2. 遗传多样性也叫基因多样性，是同种生物不同个体之间基因的差异。6.6s
  3. 易错：生物多样性的形成不只是新物种不断形成的过程，还包括遗传多样性和生态系统多样性的形成。9.7s

生物多样性的形成04#

生物多样性是协同进化的结果
  1. 原核 → 真核
  2. →单细胞 → 多细胞
  3. →水生 → 陆生
  4. →简单 → 复杂
  1. 1有性生殖出现后，生物进化速度明显加快
  2. 2寒武纪大爆发大量动物在短时间内出现
考法
有性生殖实现基因重组，增强变异的多样性 → 进化速度加快
视频原话4 句
  1. 考点四，生物多样性的形成是协同进化的结果。4.9s
  2. 进化历程：生物由原核到真核、由单细胞到多细胞、由水生到陆生、由简单到复杂、由低等到高等。9.9s
  3. 两个关键事件：有性生殖的出现，使生物进化速度明显加快；寒武纪大爆发，大量动物在短时间内出现。10.0s
  4. 考法：有性生殖实现了基因重组，增强了生物变异的多样性，所以进化速度加快。8.2s

进化理论在发展05#

中性学说
大量基因突变是中性的；决定进化方向的是中性突变的逐渐积累
间断平衡学说
物种长期稳定与迅速形成新种交替出现
考法
仍有争论；更多学者认为不能否认自然选择的作用，自然选择学说仍是研究的基础
视频原话3 句
  1. 考点五，生物进化理论在发展。中性学说：大量的基因突变是中性的，决定生物进化方向的是中性突变的逐渐积累，而不是自然选择。13.1s
  2. 间断平衡学说：物种形成并不都是渐变的过程，而是物种长期稳定与迅速形成新种交替出现的过程。9.5s
  3. 考法：这些观点仍有争论，更多学者认为不能否认自然选择的作用；以自然选择学说为核心的进化理论，仍是各方面研究的基础。12.2s

现代生物进化理论06#

  1. 1适应是自然选择的结果；种群是进化的基本单位
  2. 2进化是协同进化的过程；进化导致生物多样性
  1. 突变和基因重组原材料
  2. →自然选择决定方向
  3. →基因频率定向改变进化实质
  4. →隔离
  5. →新物种
解题方法
答进化题抓主线：突变重组 → 自然选择 → 基因频率改变 → 隔离 → 新物种
视频原话4 句
  1. 考点六，现代生物进化理论的主要内容。适应是自然选择的结果；种群是生物进化的基本单位。9.6s
  2. 突变和基因重组提供进化的原材料，自然选择导致种群基因频率的定向改变，进而通过隔离形成新的物种。10.2s
  3. 生物进化的过程，实际上是生物与生物、生物与无机环境协同进化的过程；进化导致生物多样性。9.2s
  4. 解题方法：答进化题，抓住一条主线——突变重组 → 自然选择 → 基因频率改变 → 隔离 → 新物种。10.5s

    说法错误：也发生在生物与无机环境之间
  2. 2捕食者的存在有利于增加物种多样性
    说法正确。
  3. 3生物多样性包括遗传多样性、物种多样性和生态系统多样性
    说法正确。
  4. 4生物多样性是协同进化的结果
    说法正确。
  5. 5中性学说认为决定生物进化方向的是自然选择
    说法错误：认为是中性突变的逐渐积累
  6. 6种群是生物进化的基本单位
    说法正确。

相互影响、共同进化，形成多样性！
