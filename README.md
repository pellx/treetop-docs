# 树梢文档 · 高中知识站点

树梢文档（Treetop Docs）是一个面向高中全学科的知识点讲义站点。每个知识点配有语音讲解、考点拆解、易错点与解题方法，站点为纯静态 HTML/CSS/JavaScript，无外部网络依赖。

在线阅读：**[树梢文档 GitHub Pages](https://pellx.github.io/treetop-docs/)**。

当前收录 **生物学 · 人教版 2019 五册，共104期、732个考点、4012段音频**。五册均从已有 Remotion 场景与组件转换为 HTML 和内联 SVG；必修1的25期已使用与其余四册相同的转换流程更新：

|---|---|---|---|---|---|---|
| 必修1《分子与细胞》 | `biology/required-1/` | `#/bx1` | 6 | 25 | 174 | 讲义已定稿 |
| 必修2《遗传与进化》 | `biology/required-2/` | `#/bx2` | 6 | 24 | 164 | 讲义已定稿 |

## 快速开始

- **连播模式（推荐）**：打开 [index.html](./index.html)。首页是五册总索引；点一册进入本册目录，左侧目录、搜索和播放清单都只在本册内，正文在中间 iframe 里切换，翻页不打断语音，一期播完自动续播本册下一期，播到本册最后一期停止。
- **单页模式**：打开 [biology/required-1/bx1-01.html](./biology/required-1/bx1-01.html) 等任一页面，页面自带本册目录与播放器，只播放本期。
- **使用说明**：[guide.html](./guide.html)。
- **本地服务器**：在仓库根目录运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000/`；同一局域网内的手机也可访问。
- **深链**：`index.html#/bx1`（必修1 本册目录）、`index.html#/bx1-ch2`（第 2 章）、`index.html#/bx1-01/p3`（第 3 个考点）、`index.html#/bx1-01/co3`（某句旁白）。

## 思维导图

- **学科思维导图**：`index.html#/map/bio`，8 个知识领域从中心向外发散，可叠加 4 条跨册主线。
- **全书思维导图**：`index.html#/map/bx1` … `#/map/xb3`，本册各部分逐层展开。
- **局部聚焦**：进入领域后，主干在左、子集在右。点卡片先选中，再按卡片提供的“读讲义”或“看思维导图”打开对应内容。顶栏“↩ 回到思维导图”恢复阅读前的位置。
- 三种组织逻辑：知识关系、大题任务、推导方法，统一用关系图呈现；选中节点后在右侧信息卡里看成列内容。
- 一个领域的模块共用一张关系图时，领域目录直接列出各模块。选中任一模块后点“看思维导图”，即可打开本领域的同一张图。
- 一张关系图只覆盖一个模块时，图卡直接列出该模块的讲义或单元。图卡标注直接下级的类型、数量和讲义的考点总数。
- 所有考点都能从所在册的思维导图到达；未整理的部分按讲义顺序列出并如实标注。数据维护与覆盖说明见 [docs/knowledge-network.md](./docs/knowledge-network.md)。

所有站内链接均使用相对路径，仓库可以放在任意目录或子路径下直接打开。

## 设计约定

- 颜色集中在 [assets/css/site.css](./assets/css/site.css) 顶部的 `:root` 变量中，`html[data-theme="dark"]` 提供深色模式同名变量，规则里只引用变量。
- 正文强调色使用对比度 ≥ 4.5:1 的文字色；填充色只用于底纹、边线和进度条。
- 全站使用直角边框；标题以深色文字、浅色底纹和左侧色条区分层级。
- 左侧目录支持拖拽调整宽度（双击复位）、整本书全部展开/收起、按章展开考点、按节单独展开考点。
- 页面在桌面与手机宽度下均可使用；手机端目录为抽屉式。

## 键盘快捷键

| 按键 | 功能 |
|---|---|
| 空格 | 播放 / 暂停当前朗读（输入框内不拦截，且不滚动页面） |
| 小键盘 4 / 6 | 上一句 / 下一句；连播模式在本册内跨期继续，单页模式只在本期内切换 |
| ← / → | 上一句 / 下一句（笔记本备选） |
| Ctrl / ⌘ + K | 聚焦搜索框 |

## 内容与制作原则

- 五册均直接转换既有 Remotion 场景、组件和元数据中的内容，不另写讲义，也不强制补齐提示类别。必修1原版已在仓库外完整备份，更新保留原有旁白和音频。
- 原表格、分类树和流程转换为网页结构，图示保留为内联SVG；逐步出现的内容合并保留，发生替换的阶段单独呈现。
- 正文块绑定对应旁白，点击 ▶ 从该句开始播放，播放时对应内容高亮。
- 视频动画、字幕浮层、封面和结束卡不属于网页正文；导读和判断题使用现有网页模板。
- 本仓库保存可直接发布的静态站点；Remotion源工程、转换工具和私有会话日志不随仓库分发。

## GitHub Pages

站点通过本仓库 `main` 分支的根目录发布，无需安装依赖或执行构建。根目录的 `.nojekyll` 保证HTML和静态资源按原样提供。

后续更新此项目并推送到 `main` 后，GitHub Pages会自动更新在线站点。
