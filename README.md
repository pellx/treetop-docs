# 树梢文档 · 高中知识站点

树梢文档（Treetop Docs）是一个面向高中全学科的知识点讲义站点。每个知识点配有语音讲解、考点拆解、易错点与解题方法，站点为纯静态 HTML/CSS/JavaScript，无外部网络依赖。

当前已发布 **生物学 · 必修1《分子与细胞》**：25 期、174 个考点。目录结构按「学科 / 教材」组织，后续可按同一结构扩展化学、物理、数学等学科。

## 快速开始

- **连播模式（推荐）**：打开 [index.html](./index.html)。左侧目录、搜索和播放器在外壳中，正文在中间 iframe 里切换，翻页不打断语音，一期播完自动续播下一期。
- **单页模式**：打开 [biology/required-1/bx1-01.html](./biology/required-1/bx1-01.html) 等任一页面，页面自带目录与播放器，只播放本期。
- **使用说明**：[guide.html](./guide.html)。
- **本地服务器**：在仓库根目录运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000/`；同一局域网内的手机也可访问。
- **深链**：`index.html#/bx1-01/p3`（第 3 个考点）、`index.html#/bx1-01/co3`（某句旁白）、`index.html#/bx1-ch2`（第 2 章）。

## 扩展新学科 / 新教材

1. 按 `学科/教材` 建目录，例如 `chemistry/required-1/`、`biology/required-2/`；页面文件名沿用 ASCII 稳定编号（如 `bx2-01.html`）。
2. 在 [assets/js/site-data.js](./assets/js/site-data.js) 的 `books` 中追加教材条目，并把每期的 `file` 指向新页面。
3. 音频与图片按编号放入 `assets/audio/` 与 `assets/img/`，在 [assets/js/playlist.js](./assets/js/playlist.js) 和搜索索引中登记。
4. 新页面的导航、面包屑、上一节/下一节等站内链接全部使用相对路径。
5. 新增学科后，可在首页汇总入口中并列展示；现有页面无需改动路由规则。

## 设计约定

- 颜色集中在 [assets/css/site.css](./assets/css/site.css) 顶部的 `:root` 变量中，`html[data-theme="dark"]` 提供深色模式同名变量，规则里只引用变量。
- 正文强调色使用对比度 ≥ 4.5:1 的文字色；填充色只用于底纹、边线和进度条。
- 全站使用直角边框；标题以深色文字、浅色底纹和左侧色条区分层级。
- 左侧目录支持拖拽调整宽度（双击复位）、整本书全部展开/收起、按章展开考点、按节单独展开考点。
- 页面在桌面与手机宽度下均可使用；手机端目录为抽屉式。

## 键盘快捷键

| 按键 | 功能 |
|---|---|
| 空格 | 播放 / 暂停当前朗读（输入框内不拦截，且不滚动页面） |
| 小键盘 4 / 6 | 上一句 / 下一句；连播模式跨期继续，单页模式只在本期内切换 |
| ← / → | 上一句 / 下一句（笔记本备选） |
| Ctrl / ⌘ + K | 聚焦搜索框 |

## 内容与制作原则

- 讲义只依据每期的旁白与考点材料整理，不引入材料之外的事实、数据、年份和人名。
- 旁白是骨架：每个考点保持旁白的术语与逻辑顺序，把并列信息整理为段落、列表和对比表格。
- 每个考点固定包含三类提示：高考怎么考、易错点、解题方法。
- 每个讲义段落绑定对应的旁白行，点击段落旁的 ▶ 从该句开始播放，播放时对应段落高亮。
- 本仓库保存的是生成后的静态站点；生成与校验工具不随仓库分发。
